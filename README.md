# trureturing experiments

Experimental programs, datasets, numerical certificates and research reports for [trureturing](https://github.com/the-omega-institute/trureturing).

The original paths are preserved under `docs/reports/` and `experiments/`. Run commands from this repository root; experiment-specific requirements and instructions accompany their programs. Lean proofs and their formal evidence belong to the main repository.

This repository is private. Access requires membership or collaborator permission. Third-party licenses and notices accompany the relevant material.
