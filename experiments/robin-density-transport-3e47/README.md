# Density-weighted Robin transport certificate

The owning application is `Library/ArithSums/nicolas2025comparison.md`,
GAD1–GAD8 in the trureturing repository. It consumes the existing Polak
W5/X1/X2 complete zero-density transfer and GAK whole-law transport,
coefficient remainder and unrestricted reserve.

```sh
python3 experiments/robin-density-transport-3e47/certificate.py \
  --output experiments/robin-density-transport-3e47/result.json
```

The 24 positive rational comparisons certify the changed numerical
enclosures for `8 * 10^46 < A <= 3 * 10^47`: logarithms, an exponential
prefix, density mass, order-nine support and complex normalization, and
the four complete allowances. The signed allowance is less than `19/25`;
the reused unrestricted reserve exceeds that bound by more than `1/20`.
Decimals printed by the program are displays; `result.json` stores the
actual rational margins.

The logarithm enclosure is the existing GAK25 series. The all-frequency
sine bound, published density theorem, verified zero population and full
analytic transport are reused inputs. This program does not evaluate the
actual signed integral, rerun zero verification, prove the analytic
inference in Lean, establish Robin for all smaller integers, bound the
least counterexample or resolve the unbounded RH goal.
