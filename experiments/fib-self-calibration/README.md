# Retained self-calibration suppliers

These original supplier files belong at their existing relative paths:

* `fixed-b-and-negative-child/negative-child-exhaustion.py`: original-clock
  identities, normalized carrier and zero-safe drift pseudo-remainder, and
  Gaussian-rational translations.
* `fixed-b-and-negative-child/negative-j-seed.py`: source response circuit and
  the existing exact negative-child J seed certificate.
* `quantitative-arc/quantitative_certificate.py`: original quantitative-arc
  certificate; the common-base discovery consumer reads its literal `blocks`
  assignment without executing its arc computations.

All three are byte-for-byte copies of the original private experiment sources.
They have no additional local input files for the portions consumed here.
Their owning paths and mathematical implementations are preserved. The full
original supplier subexperiments and unrelated result files are not required
by this dependency closure.

The common-base [README](../fib-common-base-6ada6767-attempt-1/README.md) owns
the reproduction commands and dependency versions. Its
[inventory](../fib-common-base-6ada6767-attempt-1/DEPENDENCIES.json) records
original and retained SHA-256 hashes, source checkout revisions (the files
themselves were untracked there), license provenance, and every consumer edge.
These same-project sources use the repository's Apache-2.0 [LICENSE](../../LICENSE).
No third-party source is vendored here.
