# FourPath positive-prefix population and gain certificates

These certificates support Section 51 of
`docs/develop/theory/QUANTUM_REALITY_FOUR_PATH_FULL_RECORD_RECOVERY_BOUND_CONTINUATION_IV.md`
in the main trureturing repository. The mathematical domain is the original
normalized pure effect and one whole feedback, with ordinary transpose,
true joint distance and one common scalar. The positive-active conclusion
covers every `0 < xi <= xiStar`; the negative branch and the complete global
first-contact problem remain separate obligations.

Run from this repository root with Python 3.12 or newer and no dependencies:

```sh
python3 experiments/auric/four-path/positive-prefix-population-gain-6aeb0aa2fba56a3ea8c3ca9c/certify.py
python3 experiments/auric/four-path/positive-prefix-population-gain-6aeb0aa2fba56a3ea8c3ca9c/verify.py
```

`certify.py` writes `certificate.json` using outward intervals on the
`2^-96` grid, checking all 14 inequalities and the complete closed covers
of 630 leaves. `verify.py` reads that certificate, uses independent exact
Fraction intervals with outward `2^-128` roots and first-order jets of the
original expression, and writes `verification.json`. Its 1,235 subleaves
include refinements needed for the independently differentiated expression.
The algorithms use integer and rational decisions throughout.

data are `2c54932b6f9a7eb9a838e5be71e91d97e10027be` and
`e6854b4057168ac0ffbbbc0b3e4e1468203de0f1`. Their FourPath suppliers agree
