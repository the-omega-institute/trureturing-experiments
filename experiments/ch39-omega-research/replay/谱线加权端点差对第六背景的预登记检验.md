# 谱线加权端点差对第六背景的预登记检验

在 19×19 谱对表中，第 0 线的四个可行搭档为 15、18、285、323。以两荷谱的零基序号表示，依次为 (0,15)、(0,18)、(15,0)、(17,0)。每一对坐标都使一个荷处于最低谱值。对具有乘积端点 \(a\)、算术平均端点 \(b\)、带符号线权 \(w\) 的线，定义 \(s=|w|(b-a)\)。这是把线性位置读数从一端移到另一端时带权读数的最大绝对变化。每条线的训练分数取五组实际壳权的 \(s\) 的算术平均，不使用重场谱、耦合斜率或联合校准解。按分数取前四这一规则，是在已知五组可行线对后选择的。

**留出预测。** 以 (2306888100090,2345676) 为第六组。先取该背景自身的 \(s\)，预测其前四线的集合与五组训练分数的前四一致，为 {15,18,285,323}。另预测在前四组标尺为 0.007、第五和第六组均为 0.006 时，四个搭档分别与第 0 线组成的线对都允许六组在 \(10^7\) GeV 共同正交汇，并从电弱能标到交点全程为正。这一预测允许共同重新分配 359 条共用线，另外两条线可在六组间各用不同分布。继续要求各组精确达到 \(K=1,W=10^{-122}\)。若出现任何一个连续域认证的不可行线对，第二个预测即出现反例。若第六组即使全部谱线自由也排除，则四个搭档均判失配。有限网格搜索失败只作待定。
