# 三枚相邻编号的固定夸克振幅与共享正谱权

取 \(N=2\,306\,888\,100\,085\)。固定已在 \(N\) 实现 1 TeV 同表中心值的实三维物理空间及上下两块目标振幅。各部门在实际十九站拉普拉斯的本征值升序上，重新任选十九个非负响应。要求同一部门在所列每个编号都以相同的十九项响应实现自己的目标矩阵。上下部门可独立选权。

| 编号 | 上部门 | 下部门 |
| --- | --- | --- |
| \(N-1\) 单独 | 不可行 | 不可行 |
| \(N\) 单独 | 严格正权可行 | 严格正权可行 |
| \(N+1\) 单独 | 不可行 | 严格正权可行 |
| 三个编号中任取两点共享 | 不可行 | 不可行 |
| 三点共享 | 不可行 | 不可行 |

下部门在 \(N\) 和 \(N+1\) 各自可拟合。即使独立于原有中心谱权重新优化，仍无跨这两个编号的共同非负解。涉及左邻点的组合已由其单点排除。上部门的每一种两点组合至少含一个不可行邻点。

## 单点的六个实方程

固定中心见证的参数 \(a=0.02145737\)、平凡平面基角 \(\theta=-0.44525\) 及目标味基相位 \(1.064\)。三循环不变的四站 Hermite 块在“极点、三射线均匀和、补平面实基”的坐标内有六个实自由度。记其坐标为
\[
c(Q)=(Q_{11}, Q_{22},\Re Q_{12},\Im Q_{12},Q_{33},\Im Q_{34}).
\]
对本实三维嵌入，\(0<a<1\) 使压缩在这六维空间上为单射。具体地，在适应嵌入的基里，三维压缩读得的 \(p,s,t,k,w\) 唯一确定平凡块的三个元素 \(p,k/b,(t-a^2s)/b^2\) 和补平面块的对角元 \(s\)、非对角元 \(-iw/a\)，其中 \(b=\sqrt{1-a^2}\)。故实现固定的三阶矩阵等价于实现固定的六维目标 \(d_q\)。

对每个部门 \(q\) 和编号 \(n\)，以十九个原生谱投影的四站压缩坐标为列，得到 \(C_{n,q}\)。部门内除以第三代 Yukawa 作归一化。对应的可行性条件为 \(C_{n,q}w=d_q\)、\(w\ge0\)。同一权向量需覆盖多个编号时，把矩阵和目标按编号竖排。共享的对象是升序谱位置上的响应值，邻点间无需假定对应位置的本征值相同。

## 严格正解与分离证书

在 \(N+1\) 的下部门，先给每条谱线赋权 \(10^{-9}\)，再给第 \(1,2,6,9,12,16\) 条谱线增加正量。证书验证这六列组成的矩阵可逆，直接解线性方程并验证六个增量皆严格正。六个归一化增量依次约为 0.01482895、7.865259、120.75814、8970.60343、7.484017、0.000854402。该见证容许自由指定每条谱线的响应大小。所有单点和多点的不可行判断均由四个整数线性泛函及其逻辑推论得到。

分别记 \(C,d\) 为对应的单点或堆叠数据。每个分离泛函 \(L\) 均满足 \(\min_{1\le j\le19} L\cdot C_j>0\) 和 \(L\cdot d<0\)。因此非负权的任意线性组合无法给出目标。下表按六坐标的顺序列出整数系数，双点行先中心后右邻。脚本用 Arb 逐列复核内积的严格符号。

| 部门、编号 | 整数分离泛函 |
| --- | --- |
| 上，\(N-1\) | \((316940,287236,-696693,575913,1,0)\) |
| 下，\(N-1\) | \((907284,-66930,-409217,70099,1,0)\) |
| 上，\(N+1\) | \((532009,153927,-619776,-556026,1,0)\) |
| 下，\(N,N+1\) | \((119633,-780789,114831,57794,1,0,129597,567353,112498,-90500,1,0)\) |

在这十二个归一化坐标的欧氏范数下，双点分离泛函将下部门目标与共同响应锥的距离下界定为 0.00100947。该界由 \(-L\cdot d/\|L\|_2\) 向下舍入。

本实验固定同一物理基中的两块三阶振幅矩阵，这比仅固定六个质量和 CKM 严格。保留这些观测量时可将两块矩阵作共同酉共轭。能否通过改变其味基方位在邻点重现观测量，仍待另行判定。
