# 恢复第七壳引力双矩恰需三条最短站位边

初态取第五壳完整联合见证的荷六算子 $A_5$。在第七壳实际第三枢轴读取 $K,W$，允许的门是在贝伦德壳三条最短站位边上各自取一个实平面旋转，其余站位恒等。要同时恢复 $K=1$ 与 $W=10^{-122}$，最少必须激活 **三条不同的边**。对全部单边角度有 $W<-1$，对任意两条边的全部独立角度有 $W<-0.49$。三边可行性由独立角的精确根给出。[第五壳初态](https://github.com/the-omega-institute/trureturing-experiments/commit/d371ffb4) · [三边双矩见证](三条最短弦的独立站位旋转能恢复第七壳引力双矩.md) · [单边与双边的区间证书](ch39-fifth-seventh-minimum-shortest-site-gates.py)

按从零编号，三条边依次为 $(6,11),(7,12),(8,18)$，每对按距极点由近至远排列。取向固定为 $R(\theta)=\bigl(\begin{smallmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{smallmatrix}\bigr)$。三对站位互不相交，所以门可交换，同一条边上的多次旋转可相加为一个角。零角也在下表的闭区间覆盖内。

| 活动边 | 覆盖整个角域的闭盒数 | $W$ 的严格上界 |
| --- | ---: | ---: |
| 1 | 13 | $-1.0093$ |
| 2 | 7 | $-1.0175$ |
| 3 | 14 | $-1.0218$ |
| 1、2 | 445 | $-0.49002$ |
| 1、3 | 653 | $-0.49032$ |
| 2、3 | 2876 | $-0.490001$ |

令 $z_{ij}$ 为旋转后两条重源列在第七壳本征标架中的分量。由各门支撑不相交，每个分量精确写成常数加上各活动边的余弦项和正弦项。若源振幅为 $\ell$（十七重）、$h,k$，第 $i$ 层的振幅就是 $y_i=\ell+(h-\ell)|z_{i1}|^2+(k-\ell)|z_{i2}|^2$。对每种边集，由正余弦的全周期界和源谱上端给出逐层上界 $y_i\le u_i$。

以 $c_i$ 表示第七壳实际第三枢轴的有符号权，$g_s,m_s$ 表示破缺背景各物种的真空系数与质量平方。用无质量项 $-(\sum_s g_s)\sum_i c_i y_i^4/(8\pi)$ 包围真实真空项时，绝对误差至多为
$$
\frac{1}{4\pi}\sum_i |c_i|u_i^4
 \sum_s |g_s|\left(\frac12-E_3(m_s/u_i^2)\right).
$$
这是因为对 $v\ge0$ 有 $2(e^v-1)\ge v$，故 $x^2(1-e^{-a/x})$ 对 $x>0$ 单调不减（$a\ge0$）。将此不等式代入 $E_3$ 的积分表示便可在振幅上界处控制每一层的质量修正。三个单边及三个双边情形中，该误差均小于 $0.001439$。程序从完整的 $[0,2\pi]$ 或 $[0,2\pi]^2$ 出发，自适应二分最长的一边，对各闭格上的三角函数、重叠和有符号四次和向外取界，并计入上述质量修正。最后一列由所有终止闭格的上界取得。
