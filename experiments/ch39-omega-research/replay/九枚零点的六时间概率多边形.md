# 九枚实际零点的六时间概率多边形

取七点精确零均方字典，再加第 $i=142\,270\,715\,263$、$j=143\,921\,351\,258\,535$ 枚正零点，记两个新增概率为 $r,s$。在九点上保留归一化、原有六项时间与各概率非负，则 $r,s$ 的**最大共同下限为 $\eta_*=0.22617376849209479563\ldots$**。它唯一地在 $r=s=\eta_*$ 达到。此时旧字典中只有第 142,285,199,398 枚正零点降为零，其余六枚仍各有正概率。[原七点字典](ch39-six-time-proton-exact-zero.py) · [九点概率的区间复算](ch39-nine-point-proton-probability.py)

沿用原七点的编号顺序，记它们的时间列矩阵为 $V$、原概率为 $p^*$，新增两列为 $W$，令 $H=V^{-1}W$。七个旧点的概率恰为 $p^*-H(r,s)^{\mathsf T}$，因此其七行非负约束与 $r,s\ge0$ 给出全部可行概率。令 $y_n=[1+(\gamma_n/A)^2]^{-1}$、$D(y)=\prod_{k=2}^6[1+(k^2-1)y]$。对新增节点 $t$，矩阵 $H$ 相应列的第 $m$ 项可精确写为
$$
 H_m(t)=\frac{D(y_m)}{D(t)}\prod_{\ell\ne m}\frac{t-y_\ell}{y_m-y_\ell}.
$$
这是六次多项式的 Lagrange 插值。逐对求九条边界线的 36 个交点并检验其余约束后，留下以下四个顶点（近似值）。

| $r$ | $s$ | 取零的两个概率 |
| ---: | ---: | --- |
| 0 | 0 | 新增 $i,j$ |
| 0.22617376849210598 | 0 | 旧第 3 点、新增 $j$ |
| 0.22617376849208676 | 0.38862559940842131 | 旧第 3、7 点 |
| 0 | 0.38918387327928391 | 旧第 7 点、新增 $i$ |

第三个旧点给出 $H_{3i}r+H_{3j}s\le p_3^*$，两个系数都严格为正。因此 $\min(r,s)\le p_3^*/(H_{3i}+H_{3j})$，取等要求 $r=s$。代入这个对角交点后，其余六项严格为正。它们按第 1、2、4、5、6、7 点排列约为 $4.66865510\times10^{-11},\,0.00823747086,\,0.26067344710,\,0.11334781087,\,0.00294190261,\,0.16245183153$。若要求九点全部严格正，则 $\eta_*$ 是上确界，可沿 $r=s$ 从下逼近。

在最大共同份额处分配 $r=s=\eta_*$，两点分离证书要求它们对任何可行 105 圈作用的均方贡献严格高于 $7.55845769913\times10^{-6}$。七点精确零见证所用的那组作用权在这两枚编号上的十二面读数分别约为 $0.0147096102419,0.00307169863155$，对应均方贡献 $4.89378139103\times10^{-5}$、$2.13402470468\times10^{-6}$。其余七个角上的因子均为零，所以这组作用在最优概率分布上的全字典均方为 $5.10718386150\times10^{-5}$。[两点分离下界](ch39-six-time-positive-support.py)
