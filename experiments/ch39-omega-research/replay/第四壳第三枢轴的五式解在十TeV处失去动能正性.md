# 第四壳第三枢轴的五式解在十 TeV 处失去动能正性

第四壳的直接第三枢轴在 \(M=1.176397\times10^{14}\,\mathrm{GeV}\) 有一组荷六输运，使 \(K=1,\ W=10^{-122},\ D=R_P=R_M=0\)。固定这一解盒的十九个截止与同一组有符号实权，只改变外部探测能标 \(P\)。在 \(P=10^4\,\mathrm{GeV}\) 处，色逆耦合和中性矩阵的纯 \(T_3\) 方向均严格为负，纯电磁方向严格为正。这个判定覆盖先前给出的整个解盒。[端点共同解及主序条件](第四壳原能标的第二与第三枢轴荷六酉输运.md)

## 能标改变时的区间计算

记 \(p=P^2/M_P^2,\ p_0=M_Z^2/M_P^2\)。对第四壳实际轻重物种使用相同的 \(M_Z\) 减法，分别求 \(A_{QQ}, A_{QT_3}, A_c\)。角核按二进分段采用十三阶 Gauss–Legendre 求积及有证明的余项。在截止平方 \(x\) 的区间中点求值后，用

\[
\left|\partial_{\log x}R_\omega(x;p_0,p)\right|
\le\min\!\left(1,\frac{p-p_0}{4x}\right)
\]

包围盒内全部截止变化。这个界来自正且归一的角权、费曼参数 \(0\le u(1-u)\le1/4\)，以及两个指数之差的单调界。对弱差 \(D=A_{T_3T_3}-A_{QT_3}\)，十九个无截止端点项共享一个公共值，其总系数等于一。有限截止误差用逐项绝对值之和 \(k\sum_i|c_i|/x_i\) 控制，其中 \(k\) 由实际 \(W,Z,t\) 的质量平方决定。[全程弱差界](八个自由截止的中性动能沿程正性.md) · [本解盒的复算脚本](ch39-fourth-third-pivot-kinetic-path.py)

这个解盒在整条能标路径上满足 \(|D|<0.684757\)。十 TeV 处的直接计算和弱差界给出以下外包区间。

| 量 | 严格下界 | 严格上界 |
| --- | ---: | ---: |
| \(A_c\) | \(-75.116724\) | \(-75.116716\) |
| \(A_{QQ}\) | \(177.940021\) | \(177.940031\) |
| \(A_{QT_3}\) | \(-6.965888\) | \(-6.965881\) |
| \(A_{T_3T_3}\) | \(-7.650644\) | \(-6.281125\) |
| 中性矩阵行列式 | \(-1409.880\) | \(-1166.187\) |

## 两个正端点之间的变号

在 \(M_Z\)，色逆耦合为 \(a_3>0\)，中性矩阵的第一顺序主子式与行列式分别为 \(5a_1/3+a_2>0\) 和 \(5a_1a_2/3>0\)。在共同解端点，\(A_c>29.7103\)，中性矩阵等于 \(A_c\left(\begin{smallmatrix}8/3&1\\1&1\end{smallmatrix}\right)\)，行列式为 \(5A_c^2/3>0\)。这些量连续，因此端点五式解的色逆耦合和中性矩阵行列式各自在 \(M_Z\) 与十 TeV 之间、十 TeV 与 \(M\) 之间至少有一个零点。
