# 算术枢轴在原壳谱投影上的负轮廓与弱差

取第 $N=2\,306\,888\,100\,085$ 枚正零点处的十九站原磁拉普拉斯，保留实际的双钟和软边。把四个 RH Gram 源依次嵌入壳极点及三射线首站，用磁拉普拉斯本身的十九个谱投影读出三个主枢轴的实交叉谱权。令每层截止能量平方正比于其壳本征值，仅调一个共同正单位。在每个截止均处于 $[M_Z,M_P]$ 的条件下，第一枚枢轴在五种荷都不能消去独立中性弱差，第二、第三枚分别在五种荷都能消去它。这里每个荷、每枚枢轴单独选取标尺；要用同一组截止同时满足引力、径向势及全部中性动能条件，还须检验其余七式。[固定壳谱和区间验证](ch39-native-rh-ray-pvm.py)

## 四个源放在哪里

从六个 $96$ 位有理格取四源 Gram 矩阵 $G=LL^{\mathsf T}$，$L$ 下三角、对角正。把四个 Gram–Schmidt 方向依次映到壳极点及按坐标 $x,y,z$ 排列的三射线首站，站号为 $(14,8,7,6)$。若这些单位站向量依序记为 $f_0,\ldots,f_3$，则原向量 $g_i=\sum_{k=0}^iL_{ik}f_k$，顺序残向量为 $L_{ii}f_i$。对第 $j$ 个简单壳谱值的正交投影 $\Pi_j$，取
\[
 c_{ij}=\operatorname{Re}\frac{\langle g_i,\Pi_j f_i\rangle}{L_{ii}},
 \qquad i=1,2,3 .
\]
这些是给定站点相位约定下的无量纲实权，有 $\sum_j c_{ij}=1$。程序用 $256$ 位 Arb 验证每荷十九个本征值为正且彼此分离，由含误差包围的本征向量及其范数直接构造投影。对任意荷，取共轭荷会共轭磁矩阵和全部复权，因此实截止权相同。[原始 Gram 读数与抽象交叉谱的锐负量](四个算术Gram源的交叉谱能承担多少截止负权.md) · [三射线与原壳磁联络](ch39-three-ray-chiral-boundary.py)

三种循环排列给相同的复权。每个简单本征向量有确定的循环特征标：非平凡特征标在极点为零，在三个射线站上的分量相位依次相差三次单位根；平凡特征标的三个射线分量相等。因此交换最后两条射线，对非平凡特征标把交叉权共轭，对平凡特征标保持不变。六种射线排序给出同一套实权。复读数仍能辨别某些取向。例如荷一、第二枚枢轴、第十四个本征值的复权虚部在原顺序介于 $-6.094$ 和 $-6.091$，交换最后两个站后介于 $6.091$ 和 $6.094$。

## 负原子与负固有时区间

先仅要求截止的平方位置 $x_j=Q_j^2/M_P^2$ 随有序本征值非降，且 $p_0=(M_Z/M_P)^2\le x_j\le1$。若各层位置严格递增，固有时轮廓 $f(\tau)=\sum_j c_{ij}\mathbf1_{\{\tau\ge1/x_j\}}$ 依次取高能层的后缀和。表中 $b=\sum_j\max(-c_{ij},0)$ 为负原子总量，$a=-\min_{2\le k\le19}\sum_{j=k}^{19}c_{ij}$ 为最深负后缀的深度。每格列出 $(b,a)$，数值取近似。

| 荷 | 第一枚 | 第二枚 | 第三枚 |
| ---: | ---: | ---: | ---: |
| $1$ | $(1.064,1.064)$ | $(14.316,12.731)$ | $(161.565,137.904)$ |
| $-4$ | $(1.932,1.600)$ | $(25.704,25.476)$ | $(287.717,284.474)$ |
| $2$ | $(1.246,0.912)$ | $(18.225,18.162)$ | $(212.574,211.721)$ |
| $-3$ | $(1.082,1.081)$ | $(14.518,12.685)$ | $(159.748,137.378)$ |
| $6$ | $(2.552,2.229)$ | $(32.458,31.968)$ | $(355.380,348.121)$ |

在重多重态内部简并、背景费曼规范的一圈弱差模型中，单点贡献 $D(x)=A_{T_3T_3}-A_{QT_3}$ 严格为负且随 $x$ 递减。记 $d=-D$，允许非降位置并可合并相邻层时，达到零弱差的充要条件是 $a\ge b_*=d(p_0)/(d(1)-d(p_0))$。分部求和给
\[
 \sum_j c_{ij}d(x_j)=d(x_1)+
 \sum_{k=2}^{19}\left(\sum_{j=k}^{19}c_{ij}\right)
               \bigl(d(x_k)-d(x_{k-1})\bigr)
 \ \ge d(p_0)-a\,[d(1)-d(p_0)] .
\]
在最深后缀处分两组，前组全部置 $p_0$，后组从 $p_0$ 连续移向 $1$，即可达到下界并经过零（若下界等于零，则在终点达到）。该背景 $b_*\simeq1.865474$。因此第一枚只有荷六能以这种方式相消；荷负四虽有足够的负原子总量，能序却使其最深负后缀不足。后两枚在五荷都通过这个检验。[单一弱差的锐负量与单调性](单一弱差匹配的最小负权与唯一最优两点.md)

## 用本征值决定十九个截止的相对位置

进一步规定 $x_j=s\,p_0\lambda_j/\lambda_1$，最低截止是 $M_Z\sqrt{s}$。此时不能再把谱层逐个移动。对第二、第三枚枢轴，表中每个数的 $\pm0.001\ {\rm GeV}$ 邻域都含一个使弱差恰为零的最低截止。各区间内两个端点给相反的严格符号，由连续性得到存在性。

| 荷 | 第二枚的最低截止（GeV） | 第三枚的最低截止（GeV） |
| ---: | ---: | ---: |
| $1$ | 182.2826 | 504.9111 |
| $-4$ | 193.1119 | 544.7020 |
| $2$ | 193.4842 | 546.6290 |
| $-3$ | 181.8576 | 503.0424 |
| $6$ | 192.5750 | 541.8263 |

计算沿用 $M=1.176397\times10^{14}\ {\rm GeV}$ 的中心背景。对于 $x=c\,p_0$、$c\ge1$，以参考对数矩为常数，把 $E_1(y)+\gamma+\log y$ 展到 $32$ 阶。低端每个实参满足 $0\le y\le4/c$。当 $n\ge32$ 时其交错级数尾项由下一项控制，含系数的总误差小于 $10\cdot4^{33}/(33\cdot33!)$。各阶角矩都是 $\int_0^1s^a(1-s)^b\,ds=a!b!/(a+b+1)!$ 的有限线性组合，标量项的第二个角积分再乘 $1/(j+1)$。高能端原核的绝对值至多 $2x/p_1$，$p_1=(M/M_P)^2$。用 $c=1$ 时的直接复球积分独立核对展开式。对于第一枚枢轴，区间算术覆盖 $1/4096\le1/s\le1$，五荷的加权弱差均小于 $-0.003$。余下 $s\ge4096$ 由既有大截止余量与各荷总变差估计，得到加权弱差小于 $-0.073$。[弱差原角核与 $M_Z$ 直接积分](最低截止取Z质量的八点中性匹配.md) · [大截止余量](任意截止抵消弱三分量残差的必要代价.md)

运行 `python3 -B ch39-native-rh-ray-pvm.py --levels` 可逐层查看谱值与复权；函数 `shell_weights(root)` 返回五荷的有序谱、正序与反序投影结果。嵌入使用指定站点和原联络规范，谱值转成物理截止还采用共同标尺。上述存在性只用来匹配独立弱差，未决定这一标尺的动力学来源。
