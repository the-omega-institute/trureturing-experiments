# 第五组降低标尺后五组共同正交汇恰需两条独立线

取连续五组实际背景，壳权与重谱的零点编号为 \((2306888100085+j,2345666+2j)\)，\(0\le j\le4\)。每个背景分别精确匹配牛顿矩 \(K=1\)、真空矩 \(W=10^{-122}\)，并在共同能标达到三支规范逆耦合相等。从电弱能标 \(M_Z\) 到交点要求三支始终为正。谱线从 0 起按 \(19i+j\) 编号，分布是乘积端点与算术平均端点之间插值位置的概率测度。

前四背景截止标尺均取 0.007，第五背景取 0.006。要达成上述目标，最少两条谱线须允许其概率分布随背景而变。取第 0 与 323 线即可，对应谱对 \((0,0),(17,0)\)。其余 359 条线各自使用五个背景共用的分布，各背景保留自身的线权与重场阈值。所给布局使五组同时在 \(10^7\) GeV 精确交汇。下表给出区间证书的中心近似。[有理支撑与区间证书](ch39-five-split-scale.py)

| 背景 \(j\) | 交点共同逆耦合 | 从 \(M_Z\) 至交点的最小逆耦合 |
| --- | ---: | ---: |
| 0 | 42.53007339 | 29.60092470 |
| 1 | 41.48812202 | 28.55897333 |
| 2 | 40.60419801 | 27.67504932 |
| 3 | 40.81394888 | 27.88480019 |

每条线在每个适用背景有一个有理基点。另登记二十个有理插值位置。以每个额外份额从相应基点移至该位置引起的四个读数变化为列，五组各四个等式构成二十阶系统。程序重新计算实际零点所给的热核阈值，验证预条件矩阵可逆、二十个额外份额和每个基点的剩余份额严格为正。一圈斜率次序给出全段最小值 \(A_3(M_Z)\)，五处均大于 27.675。[两个布局的有理数据](ch39-five-split-scale-layouts.json) · [区间线性求解](ch39-one-background-specific-line.py)

要证一条不够，先限制到前四组。其已证分类只允许第 0 线独立。再允许这条线在五个背景分别使用任意连续分布，其余线共用。把各背景的两项引力残差与两项规范差按程序列出的有理方向投影。共同线对五个带权响应之和在插值闭区间取下界，第 0 线则在每个背景各取一个下界后相加。投影同时扣除了五个各自可选的比较能标在 \([M_Z,M_P]\) 的最大影响。48 阶热核展开单独扣除一致尾界。由此，即使各自选择能标，五处的十个规范差在引力精确时仍至少有一项绝对值大于 0.61645。[前四背景分类](ch39-four-background-crossing.py) · [五背景连续位置排除](ch39-five-split-scale.py)

第五背景单独还可作一项对照。该背景保持 0.007 时，即使 361 条线各取任意连续分布，达到两个引力目标后仍有一项规范差大于 0.2359（绝对值）。改取 0.0065，可用四个内部份额使其在 \(10^{12}\) GeV 精确交于约 38.100967，全段最小逆耦合大于 12.3454。五背景联合构造中，所有共同分布、独立分布均按联合目标校准。哪些几何条件能选择这些标尺和分布，仍是开放问题。[0.007 的全线自由排除](ch39-fifth-background-single-line.py) · [0.0065 的正交汇构造](ch39-five-split-scale.py)

在复算包解压目录运行 `python3 ch39-five-split-scale.py`，可复核数字、份额和两条独立线的必要性。
