# 用原壳的三角形读出两个尺度，检验两只钟何时可区分

在给定的十九点壳上，仅用邻接关系和原整数坐标的平方弦距，可以逐项读出 $(32,724)$。取全图度数最小的站点，看它们之间的边。对每条这样的边，把经过它的三角形的三个平方边长由小到大排列。每条边都有唯一一种三角形边长组，在每个位置都达到最大值。这组平方边长为 $(32,724,804)$，其前两项恰与联合见证处的两个整数尺度一致。这一读法的输入无需零点高度、物理窗口或两钟边标记。[物理窗口内的整数尺度唯一性](ch39-joint-integer-scale-pairs.py)

**同一份三角形表。** 全图有 19 个顶点、135 条边、529 个三角形。六个最低度顶点的度数均为 10，它们的诱导子图恰有三条互不相交的边。以其中任何一条为底边，其平方长度均为 32，经过它的九个三角形给出同一张表。

| 其余两条边的平方长度，由小到大 | 每条底边上的三角形数 |
| --- | ---: |
| $(152,152)$ | 1 |
| $(216,296)$ | 2 |
| $(244,244)$ | 1 |
| $(504,632)$ | 2 |
| $(544,544)$ | 1 |
| $(724,804)$ | 2 |

因此三份表独立给出同一最大边长组。若从已有的两类钟边出发，全部同时含两钟的三角形只有两种，每种各六个，平方边长组分别为 $(32,724,804)$ 和 $(200,724,804)$。

**去掉度量后的严格障碍。** 用复算脚本从零开始的编号，三条最低度边的端点为 $(0,2),(1,3),(4,5)$。每对端点除彼此外都具有完全相同的邻点。同时交换三对端点并固定其余顶点，是整个无权图的自同构。它将全部六条 724 边按方向送至六条 804 边，也将后者送回前者。因此向同一张裸图分别标记其中一类边，所得两个有标记图同构。任何在站点重编号下不变的无权计数以及标记邻接谱，在两者上相同。

**32 的另一项计数。** 保留两钟的频率和定向原生三角相位，96 个有钟面在坐标三循环下分为 32 个自由轨道。逐面以整数对 $(a,b)$ 表示 $(a+ib\sqrt{867})/|a+ib\sqrt{867}|$，按三个频率 $x,y,x-y$ 分别得到 14、14、4 种标签。每种恰为同一轨道的三张面，全部 32 种相位互异。把一个相位与其共轭合并会得到 16 种。这说明要把 32 解释为计数，定向约定是实质输入。

原生联络还给出可观测的两钟差别。在各自 42 张纯钟面上平均 $\sin^2(\arg z)$，724 钟得 $1434836979746861489/226326626341217748724\simeq0.00633967$，804 钟得 $4653327456422367540005/948664220496809995044412\simeq0.00490514$。若取平均余弦的较大者，804 钟以约 0.71191449 高于 724 钟的 0.71142887。这两个自然读数给出相反的选取，指定读数的物理理由仍须由作用或测量给出。

上述三角形读法把原壳度量、既定整数坐标单位以及最低度边的极值规则作为假设。整数尺度唯一性的既有证书把 (32,724) 分别解释为中心偶倍率和质量分母，使用了给定的曲率、规范与阈值窗口。几何上的读数一致已经可复算；从原壳动力学推出这两个量在质量公式中承担这些角色仍属开放问题。[三角形表、交换自同构与整数相位计数](ch39-native-scale-triangle-profile.py)
