# 下一壳七线最优轻上型质量的有限整数证书

冻结完整味见证在第 $2\,306\,888\,100\,087$ 壳的十九个上型振幅，移至第 $2\,306\,888\,100\,088$ 壳的四站 $(14,8,7,6)$。允许任意十九维酉输运与任意四站三平面。以下严格界由固定整数表通过有限次整数比较得到：
$$
 \frac{71789}{10^{10}}<\min_{U,F}y_u(U,F)<\frac{71792}{10^{10}} .
$$
归一化上型参考窗上端为 $6.29\times10^{-6}$。[整数核验器](ch39-next-shell-seven-ray-integers.py) · [整数外包表](ch39-next-shell-seven-ray-bounds.tsv)

## 整数输入的来源

公分母为 $S=10^{16}$。表首记录壳号和四站顺序，之后的层号从一开始。每对端点均为包含真实量的闭区间的整数分子。

| 行标记 | 其余各列 |
| --- | --- |
| 指定输入的三行 | `scale`、`shells`、`sites` 各接其值 |
| `weight` | 源层号、该层上型振幅的下端与上端 |
| `ray` | 目的层号，依次为 $|a|^2,|b|^2,\operatorname{Re}(a\bar b),\operatorname{Im}(a\bar b)$ 的四对端点 |
| `character` | 字符号、目的层号、该层字符投影概率的两个端点 |

其中 $a,b$ 是目的本征线在极点与三边界等幅和上的坐标。三循环对称与简单谱给出七条平凡射线及每个非平凡字符各六条线。Arb 溯源程序重放十八参数盒、原训练源权及两个实际壳的谱，使用各盒坐标向外舍入后的实际半宽。每项乘 $S$ 后取下端向下整、上端向上整；这个整数表是有限核验器的输入假设。实际壳的零点高度和谱投影仍由 Arb 认证。[Arb 溯源程序](ch39-next-shell-seven-ray-table.py) · [从实际谱到七线极值的证明](冻结完整见证的十九个振幅后任意新输运均排除下一壳轻上型窗.md)

## 有限比较

任一四站方向的读数在酉输运下的最小值等于方向概率与源振幅的逆序配对。两个单字符方向直接比较六项点积。对平凡二阶块，令 $\ell_i,h_i$ 分别为源权下端与上端的第 $i$ 小值。按源权升序秩 $1,\ldots,7$ 对七条射线的每个分配 $\pi$，其真实矩阵夹在用 $\ell_{\pi(i)}$ 与 $h_{\pi(i)}$ 构成的两个矩阵之间；这是各射线投影半正定的结果。

把加权矩阵各项统一写成分母 $S^2$。对于下界 $L=71789/10^{10}$，在下端权矩阵的两对角上减去 $LS^2$，所得两个对角下端须为正，其积须大于非对角实部、虚部平方上界之和。这是二阶厄米矩阵正定的判别。整数核验器在全部 $5040$ 个排列上证实这些严格比较。

按目的层 $(1,4,7,10,12,16,18)$ 依次分配升序源权秩 $(3,7,6,4,5,1,2)$。对这个排列取上端权矩阵，减去 $(71792/10^{10})I_2$ 后，整数比较给出一个负方向。酉矩阵可按此分配把源本征线送至目的本征线，再以包含最小本征方向的三平面实现相应质量，从而得到严格上界。

在本目录执行下列命令。第一条只用 Python 标准库，第二条从谱输入重算并逐字节比较表文件。

```sh
python3 -I -S -B ch39-next-shell-seven-ray-integers.py
python3 -B ch39-next-shell-seven-ray-table.py
```

在需要重新生成表文件时，给第二条命令添加 `--write`。
