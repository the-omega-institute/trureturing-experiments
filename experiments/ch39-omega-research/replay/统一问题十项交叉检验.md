# 统一问题的十项交叉检验

原第 39 章、现 §33.9 的四个物理问题仍需从统一作用量确定动力学、物质内容与观测。下表记录各项检验实际覆盖的范围，以及可从本目录独立运行的证书。所有夸克数值均使用同一套 1 TeV 参考窗。

| 项目 | 本轮所得 | 证据 |
|---|---|---|
| 1. 独立制备的连续中心解 | 四个端面的最小分离量分别大于 1.6916、1.7574、0.4388、0.4352。可按目标选择共同换基实现指定 CKM 或其共轭。 | [四面存在性证书](上下型各用独立制备背景时可达完整夸克中心目标.md) · [从相对谱辨识 CP 所需的模长](相对奇异谱与两项混合模长辨识夸克CP面积.md) |
| 2. 保留 724 共同钟 | 即使独立改变另一钟与目的轻带，两个相邻比仍至少有一个低于数据下界。 | [三角度全域排除](共同724钟的夸克排除与两个实际零点的独立制备.md) |
| 3. 保留 804 共同钟 | 目标总跨度可单独精确达到。8,495 个终格已排除整张相位域同时命中两段比。 | [全域排除](ch39-shared-804-quark-gaps.py) · [标量根](ch39-shared-804-local-quark-gaps.py) |
| 4. 实际正零点独立制备 | 上型 2,345,666、下型 964,890。共用按目标校准的可逆源变换后，十项偏差各小于观测半宽的八分之一。 | [完整换基、零点编号和整盒误差](ch39-two-zero-quark-window.py) · [八个预登记邻号组合](两个夸克制备零点的邻号检验.md) · [三对源相关及三源相干权重](两个实际夸克零点要求三源同时相干.md) |
| 5. 制备相位差 | 两只原始钟各自的部门角差都须超过 0.005 弧度。任一独立制备的夸克窗解还要求正交化源坐标中共同换基的条件数超过 26.05。 | [有限钟差](两部门制备钟差与共同背景排除的稳定范围.md) · [换基代价](ch39-independent-preparation-source-condition.py) |
| 6. 三态选取 | 同背景单步在最远三站可精确降秩至一。固定首零点制备再经三站投影和轻带读回，五荷的统一下界大于 $0.00005167$。 | [秩一反例与满秩条件](最远三站的单步三源与荷五静态端点电流.md) |
| 7. 六壳引力与弱差 | 剩余十四组中，四组有共同固定谱补空间矩阵通过十二项外包矩检验。完整十八式仍待解。 | [四组整数见证](六壳补空间四组共同固定谱矩见证.md) |
| 8. 荷五静态交换 | 三站非负归一端点全域下界大于 $0.0038154$；在原八站，第 177 枚正零点允许不相交的非负端点精确相消。 | [传播矩阵与正权证书](ch39-proton-orbit-static-currents.py) |
| 9. 中性规范阈值 | 原一圈处方允许 $0\le y_t^2\le4\pi$ 后仍留下独立残差。共同能标窗内，归一截止总变差至多 25 时，完整匹配要求截止支撑低于 2.510 TeV。 | [假设、逆矩界与复算](放宽顶耦合后的独立中性规范阈值.md) |
| 10. 共同背景审查 | 用已登记的两枚零点交叉制备，相邻比分别约 526.055 和 697.924。共同换基严格消去，同背景排除依赖共同制备；跨背景这组读数也超出目标。 | [同壳与交叉对照](ch39-crossed-zero-quark-gaps.py) |

脚本使用 Python 和 python-flint。由该文件所在目录可运行 `python3 ch39-two-zero-quark-window.py` 复核具体正零点与十项味读数，或运行 `python3 ch39-shared-724-quark-gaps.py` 复核共享 724 钟的排除。有限零点实例核验编号及 Hardy 函数端点变号；实际编号上的精确中心等式以及背景的动力学选择仍待解决。
