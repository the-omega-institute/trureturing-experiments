# 固定五原子截止下的顶夸克电弱曲率

在第 \(N=2\,306\,888\,100\,085\) 枚实际 ζ 零点，固定原来对称原点的五原子联合解，给三色 Dirac 顶夸克加入背景质量 \(z_t=y_t^2\rho\)，其中 \(\rho=\phi^\dagger\phi/M_P^2\)、\(U=V/M_P^4=W/(8\pi)\)。在 \(\rho_v=(246.22/(1.22089\times10^{19}))^2/2\) 求导。取 \(y_t=0.8616\) 时，顶夸克给出
\[
 0.01032425<U_t'(\rho_v)<0.01032426,\qquad
 0.858915<U_t''(\rho_v)<0.858919.
\]
十六个重标量双重态可以精确抵消一阶导。它们却各自增加曲率：对任意实门户 \(|\lambda_j|\leq1\)，零裸项下都无法达到 \(U'(\rho_v)=0\) 与 \(U''(\rho_v)=2(0.129)=0.258\) 两个目标。在顶耦合中心值，达到驻点的门户所允许的最小曲率严格介于 \(0.904566\) 与 \(0.904570\) 之间，即最小 \(m_h^2/v^2\) 在同一区间。

\(y_t\) 取自 Antusch、Hinze、Saad 的 1 TeV、\(\overline{\mathrm{MS}}\) 输入表 2。以表列中心作为本次一圈探针的常数，再对其整个边际窗 \([0.8573,0.8659]\) 复验。全窗上均有 \(U_t'>0.01022\)、\(U_t''>0.8416\)，任意驻点的总曲率均大于 0.8863。本次只给顶夸克和十六层标量规定背景质量。规范破缺、混合和带这些改动重新拟合引力与规范权重须使用相应的破缺模型。[原论文表 2](https://arxiv.org/html/2510.01312v2#Sx1.T2)

## 顶夸克对数的符号与大小

沿用 \(x_m=(4\times10^{-15},3.5\times10^{-11},1.23\times10^{-6},0.5,1)\) 与原联合方程的精确有符号权 \(c_m\)，其和为 1。写
\[
 I(z)=\sum_m c_mx_m E_2(z/x_m),\qquad J(z)=\sum_m c_m E_1(z/x_m).
\]
从原来的无质量行中取出顶夸克的十二个费米偏振，其质量无关部分对两个导数的贡献均为零。三色 Dirac 费米子的有符号偏振数为 \(-12\)，于是
\[
 U'_t=-\frac{3y_t^2}{8\pi^2}I(y_t^2\rho_v),\qquad
 U''_t=\frac{3y_t^4}{8\pi^2}J(y_t^2\rho_v).
\]
因 \(E_1(u)=-\gamma_E-\log u+\int_0^u(1-e^{-s})ds/s\)，且归一化给出 \(-\log z\) 的精确单位系数，
\[
 J(z)=-\gamma_E-\log z+\sum_m c_m\log x_m+R,qquad
 |R|\leq z\sum_m |c_m|/x_m<10^{-19}
\]
在所用顶耦合窗内成立。中心值给 \(I(z_t)\approx-0.366029147217\)、\(41.0200<J(z_t)<41.0202\)。对数在正电弱背景上有限。

## 门户能将驻点曲率降到多少

记 \(z_j\) 为原谱中第 \(j\) 个重标量双重态的质量平方比。一次开启任意十六个门户后，令 \(s_j=z_j+\lambda_j\rho_v\)。系数
\[
 a_j=I(s_j)/(8\pi^2),\qquad b_j=-J(s_j)/(8\pi^2)
\]
已包含每层四个实标量偏振。这些量依赖门户；区间复算在 \(-1\leq\lambda_j\leq1\) 的整段上验证 \(a_j<0\)、\(b_j>0.1337\)。重标量贡献为 \(\sum_j a_j\lambda_j\) 与 \(\sum_j b_j\lambda_j^2\)，即使混用两种门户符号，二阶响应也非负。

在驻点上 \(\sum_j a_j\lambda_j=-U'_t\)。由加权 Cauchy–Schwarz 不等式，
\[
 U''_{\mathrm{总}}\geq U''_t+
 \frac{(U'_t)^2}{\sum_j a_j^2/b_j} .
\]
将分母的全域上界以及中心顶耦合的区间代入，得到 \(U''_{\mathrm{总}}>0.904566\)。若另加在驻点一阶导为零的补偿项，它必须给出小于 \(-0.646566\) 的二阶导，亦即局域 \((\rho-\rho_v)^2\) 系数小于 \(-0.323283\)。

为给出可达的上界，以未移质时的系数定义精确方向 \(u_j=-a_j(0)/b_j(0)\)，这里的 0 指门户为零。沿 \(\lambda_j=t u_j\) 直接读取已经移质的各行并计算总一阶导。在证书给出的有理二进中心与微小相对半径 \(10^{-6}\) 所定的两端，总一阶导严格异号。由连续性存在精确驻点，所有门户均介于 0.12969 与 0.15331 之间，整段包围给出驻点处 \(U''_{\mathrm{总}}<0.904570\)。这也验证了重标量对顶夸克斜率的抵消能力。

## 修复曲率至少要怎样重选五权

在中心 $y_t=0.8616$ 固定五个截止位置，允许重选任意有符号权 $c'$，只要求 $\sum c'_m=1$。记 $\eta=\tfrac12\sum_m|c'_m-c_m|$。即使只匹配 $U''(\rho_v)=0.258$，允许自由选择十六个绝对值不超过一的门户，所需最小 $\eta$ 仍严格介于 **0.77112150 与 0.77112199** 之间。这个上界只针对曲率一项。若还要求驻点或其他联合读数，任何解仍满足同一下界。

固定门户后，曲率是 $c'$ 的线性函数。半径 $\eta$ 的归一权集合是 $c+\eta(e_i-e_j)$ 的凸包，亦包含 $i=j$ 的原权。将正负改变量按总量配对即得此表示。取最小值时只需枚举 25 个顶点；对每个顶点，十六个门户的贡献又是可分别最小化的十六项。对第 $k$ 层，先在整个 $s_k=z_k+[-1,1]\rho_v$ 上用区间包围该组权给出的系数 $\tilde b_k$。因该项为 $\tilde b_k\lambda_k^2$，其最小值位于 $\min(0,\inf\tilde b_k)$ 与 $\min(0,\sup\tilde b_k)$ 之间。后一个界可按上端符号分别选门户 1 或 0 实现为可行上界。枚举顶点、相加并二分 $\eta$ 后得到所列区间。可行域紧且连通，在候选上界处已能低于目标，故沿域内路径也能达到精确等号。[权的改动与区间复算](ch39-top-background-curvature.py)

从复算目录使用 python-flint 与 SymPy 复算。

```bash
python3 -B ch39-top-background-curvature.py
```
