# 四个二次源在相邻零点的正定性筛选

在上型第 $2\,345\,666$、下型第 $964\,890$ 枚正零点上，正定源协方差有四种二次多项式表达能精确重现同一校准见证的十项读数。固定每一解的系数，沿用原三源、轻带和滤波，只替换相邻一号时，八对编号、四个解共给出 32 个候选矩阵。只有两个保持正定。它们属于同一解，其相位隔离盒中心为 $(4.890319,1.289542)$，两处分别是上型编号减一、加一而下型保持原号。若下型编号改变，则八邻域内的六种组合均无正定解。这里的检验只比较矩阵能否作为协方差。先前的相对奇异谱证书已将邻号精确落入全部十个参考窗的可能性排除。[四解的穷尽](固定两零点十项读数恰有四个厄米二次源协方差.md) · [编号邻域的排除](实际夸克零点对在前后六十四号组合中的唯一性.md) · [正定性复算](ch39-four-quadratic-source-neighbours.py)

| 四解的相位盒中心 | 八个邻号组合中保持正定的编号偏移 $(\Delta n_u,\Delta n_d)$ |
| --- | --- |
| $(1.759345,4.347800)$ | 无 |
| $(2.238043,1.510924)$ | 无 |
| $(4.890319,1.289542)$ | $(-1,0),(1,0)$ |
| $(5.380130,4.706125)$ | 无 |

对原始 Gram 矩阵和各自除以迹的 Gram 矩阵，可以分别冻结多项式系数。两种做法在中央对重现同一组协方差，其在邻号上给出同一张正定性表。每种做法的两处正定矩阵均满足 $\lambda_{\min}>3$，其余 30 个候选均满足 $\lambda_{\min}<-0.47$。

证书先将四个已穷尽的相位解分别收紧到半宽 $10^{-12}$ 的盒，检验中心雅可比预条件映射将小盒压缩到自身。用原始 Gram 基元 $I,U,U^2,D,UD+DU,i[U,D],D^2$ 的厄米坐标求系数，所用七阶子式行列式大于 $3.9\times10^{-20}$。在有界精度下由此得到每个精确系数的区间。若固定单位迹坐标下的系数，就在代入原始多项式前将邻号的上、下 Gram 矩阵分别乘以同部门中央迹与邻号迹之比。程序用区间本征值核验八处的惯性符号。

四个精确多项式在一般正定输入上也有共同的反例。取两个可同时对角化的正定矩阵，在同一坐标轴上分别取本征值 $1/1000$ 和 $1/20$，其余两条轴平分各自中央 Gram 迹的余量。这样，两部门的迹都与中央输入相等，该坐标轴上的多项式值由 $I,U,U^2,D,UD+DU,D^2$ 的标量值直接算出。对四个解，该值依次落在 $(-393,-392)$、$(-298,-297)$、$(-212,-211)$、$(-298,-297)$ 内，故都出现负本征值。对一般正定输入要求恒正，以及对有限壳读数要求正定，是适用范围不同的条件。[区间复算](ch39-four-quadratic-source-neighbours.py)

## 两个编号各前后六十四号

固定相同四组二次系数，将检验范围扩大到 $129\times129$ 个实际零点组合。每种约定下，中央一对的四个协方差均正定。下表给出其余组合的正定个数，每格先写原始 Gram 坐标的结果，再写单位迹坐标的结果。每个候选都由区间正主子式证明正定，或由一个严格负的主子式排除半正定。中央对的正定性也直接来自可逆轨道。[完整方格复算](ch39-four-quadratic-source-window.py)

| --- | ---: | ---: | ---: |
| 第一解 | 3 / 3 | 0 / 0 | 0 / 0 |
| 第二解 | 81 / 82 | 0 / 0 | 184 / 176 |
| 第三解 | 120 / 124 | 0 / 0 | 687 / 840 |
| 第四解 | 11 / 10 | 0 / 0 | 0 / 0 |

第三解是在上型前后一号同时保持正定的唯一解。继续按编号距离向外检验，固定原始系数时它在上型 $+7$ 首次失去半正定性，固定单位迹系数时在 $+14$ 首次失去半正定性。两种约定均已检查比该距离更近的所有正负偏移。若只移动下型，128 个邻号悉数排除四解。若两个部门一起移动，正定性可以恢复。对于第三解，原始坐标在 $(-2,+1)$ 已有一例，单位迹坐标在 $(-3,-1)$ 已有一例。此前的相对谱证书表明，方格中只有中央编号对可以同时进入十个观测窗。协方差在邻号保持正定和物理读数进入观测窗是两项分别检验的性质。[十项读数的有限邻域唯一性](实际夸克零点对在前后六十四号组合中的唯一性.md)
