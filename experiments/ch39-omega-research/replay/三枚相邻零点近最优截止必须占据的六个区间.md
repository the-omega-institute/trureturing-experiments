# 三枚相邻零点近最优截止必须占据的六个区间

取第 $N-1,N,N+1$ 枚实际零点，其中 $N=2\,306\,888\,100\,085$，以及共同电弱背景和门户强度 $u=0.42995401872$。要求有符号截止测度 $\mu$ 定义在 $0<x=Q^2/M_P^2\le1$，总质量为一，三个背景的引力读数均为 $K=1,W=10^{-122}$。记 $\mu^+,\mu^-$ 为 Jordan 分解的正、负部，$b=\mu^-((0,1])$。此前已证 $b$ 的下确界大于 $1\,308\,843.19304049$。[三背景的谱和七项矩条件](三枚相邻零点在电弱背景共用引力截止的负量.md)

若 $b\le1\,308\,843.19305$，所有可行测度都必须同时占据下表六个互不相交的位置区间。以首列为中心 $q_j$，取 $I_j=[0.98q_j,1.02q_j]\cap(0,1]$。表中下界适用于离散、连续及混合测度。

| 中心 $q_j$ | 必需的 Jordan 部分 | $I_j$ 中质量的严格下界 |
| ---: | --- | ---: |
| $1.70333178802223\times10^{-9}$ | $\mu^-$ | 1,057,871 |
| $2.54051739237733\times10^{-7}$ | $\mu^+$ | 1,256,561 |
| $8.96947966979927\times10^{-6}$ | $\mu^-$ | 244,466 |
| $0.0303687851337465$ | $\mu^+$ | 50,019 |
| $0.54440151704291$ | $\mu^-$ | 5,691 |
| $1$ | $\mu^+$ | 1,449 |

表内正确符号质量之和超过 $2\,616\,057$。总变差为 $1+2b$，所以超过 $99.93\%$ 的总变差落在指定窗口且符号正确。若有一个窗口完全缺少指定符号，则 $b>1\,308\,843.19449972$。另一方面，六原子可行见证的负量严格小于 $1\,308\,843.193040768$。**在给定的近最优负量预算内，离散截止最少恰需六个原子。** 对负量不限的可行测度，最少原子数仍待确定。

## 逐窗加强连续对偶

沿用七维矩列 $V(x)$ 与目标 $T$，即 $\int V\,d\mu=T$。取原对偶函数 $F$ 的六个交替插值条件与 $q_2F'(q_2)=0$。对每个窗口另解一个同样的七维线性系统，其在六中心的目标值为 Kronecker 符号 $\delta_{ij}$，在切向行的目标值为零，得到函数 $L_j$。取各系数的精确二进制中点。令 $s_j=-1,+1,-1,+1,-1,+1$ 为六个所需符号，$\tau=10^{-6}$、$\eta=10^{-10}$，置 $D_j=F+\tau s_jL_j=d_j^\mathsf{T}V$。在整个闭区间 $[0,1]$ 上，218 个自适应子段共同验证
$$
-1-\eta-\tau\,\mathbf1_{\{s_j=-1\}}\mathbf1_{I_j}
\ \le D_j(x)\le\
\eta+\tau\,\mathbf1_{\{s_j=+1\}}\mathbf1_{I_j}.
$$
程序将窗口端点向内取二进近似，按重新计算的实际函数值验证不等式。每段首先验证两个端点。如果导数在整段严格同号，就以端点控制全段。其余情况使用区间导数和均值定理，必要时二分。小 $x$ 处复用 $1/x$ 坐标下四阶展开的余项界，大 $x$ 处复用 22 阶共同质量矩展开。

对 Jordan 分解积分得
$$
d_j^\mathsf{T}T \le b+\eta(1+2b)+\tau\,\mu^{s_j}(I_j).
$$
这条不等式对任意可行的 $b$ 成立。代入给定预算即得表中的六个质量下界。令某个窗口的正确符号质量为零，则得漏窗负量下界。

六点上界使用原有一个位置可动的构造。仅在第二个窗口内移动节点，保留切向辅助列并对其零系数左右端点作 16 次二分。在缩小后的根盒上再次解带严格区间误差的线性方程。切向系数在两端反号，故盒内存在满足全部目标的六个真实原子，其负量上界为 $1\,308\,843.19304076737$。

```sh
python3 -B ch39-cutoff-window-stability.py
```
