# 中央复味空间的精确振幅在相邻实际壳上的可达性

固定中央编号 \(N=2\,306\,888\,100\,085\) 上已经给出六个 1 TeV 中心质量和完整 CKM 的复四站嵌入 \(E\)，逐项固定两个三阶物理振幅矩阵。每次在相应 ζ 零点高度重新构造十九站磁拉普拉斯，按其本征值从小到大排列十九个谱投影。令每层谱振幅在 \([0,1]\) 内自由变化，所得结论如下。[中央嵌入与两个正目标](复四站味空间以小于一的实际壳振幅精确实现夸克中心数据.md) · [邻点区间证书](ch39-complex-target-neighbour-feasibility.py)

| 编号 | 上型 \(q=-4\) | 下型 \(q=2\) |
| --- | --- | --- |
| \(N-1\) | 任意非负谱权均不可达 | 任意非负谱权均不可达 |
| \(N\) | 可达，十九个权都在 \((0,1)\) | 可达，十九个权都在 \((0,1)\) |
| \(N+1\) | 任意非负谱权均不可达 | 可达，十九个权都在 \((0,0.396)\) |

中央与右邻的下型分别可达，但若要求同一层序使用同一个权，在这两个编号上同时达到精确下型目标也不可能。因而三个编号共用一套上型权和一套下型权的方案同样被排除。以上检验固定物理标架中的两个完整振幅矩阵。若只指定质量与相对 CKM 而允许各编号另选共同味基，目标集合会扩大。

## 从四站线性分离到三源目标

记 \(P_{h,j}\) 为编号偏移 \(h\) 处第 \(j\) 层的谱投影在四站上的主块，\(U\) 为固定四站平凡双重态，即极点及等权射线的平面，\(W=U^\perp\)。\(U\) 内以极点和等权射线为正交轴。对每个与三循环交换的厄米块 \(M\)，记
\[
 c(M)=(M_{00},M_{11},\operatorname{Re}M_{01},\operatorname{Im}M_{01}).
\]
两个中央三源目标分别有唯一的三循环不变四站扩张 \(T_u,T_d\)。复算把四站六个厄米基元压到同一个 \(E\)，并检验六个像的 Hilbert–Schmidt Gram 行列式严格位于 \((0.00038973632,0.00038973633)\)。故在任何编号匹配给定三源矩阵，都必须在四站上精确匹配对应的 \(T_q\)。

对整数四元组 \(v\) 定义有理泛函
\[
 \ell_v(M)=v\cdot c(M)-10^{-5}\operatorname{tr}_W M.
\]
下表中，单个编号的列值是 \(\ell_v(P_{h,j})\)，目标值是 \(\ell_v(T_q)\)。共用两编号时，列值是两个泛函在相同层序上的值之和，目标值也按两项求和。每个严格上界已覆盖全部十九列。

| 偏移与部门 | 有理泛函的整数四元组 | 全部列值严格小于 | 目标值严格大于 |
| --- | --- | ---: | ---: |
| 左邻上型 | \((-10,0,2,3)\) | \(-1.70\times10^{-9}\) | \(1.1331\times10^{-4}\) |
| 左邻下型 | \((-91,7,20,-35)\) | \(-5.22\times10^{-10}\) | \(8.9513\times10^{-4}\) |
| 右邻上型 | \((-272,19,125,-26)\) | \(-2.89\times10^{-9}\) | \(1.3592\times10^{-3}\) |
| 中央与右邻下型 | 中央 \((-69,9,-30,8)\)，右邻 \((61,-5,23,-1)\) | \(-1.94\times10^{-9}\) | \(8.7133\times10^{-4}\) |

非负权组合的泛函值至多为零，因此各行中严格正的目标值给出分离。最后一行中若允许两个编号分别选权，两个列值便不能按同一权相加，这也解释了逐个编号的可行性为何能与共享权的排除并存。

## 右邻下型的严格内点

右邻七个平凡表示层中，按一基层序取第 6、7、10、12 层作为未知量，其余三个赋 \(10^{-9}\)。两个非平凡特征方向各有六层，全组分别取中央目标指定的字符振幅。由四站平凡双重态的四个实坐标解实四阶线性系统，矩阵的区间行列式与零严格分离。所得谱振幅按相同数值分组如下。

| 右邻下型层序 | 物理振幅，约 |
| --- | ---: |
| 1、16、18 | \(10^{-9}\) |
| 2、4、8、11、14、17 | 0.15377480143 |
| 3、5、9、13、15、19 | 0.000010438810739 |
| 6 | 0.39517344983 |
| 7 | 0.035601308021 |
| 10 | 0.082204819174 |
| 12 | 0.040019536467 |

精确内点由四阶方程及中央目标的两个字符值指定。320 位 Arb 复算逐个检验十九个权严格位于 \((0,0.396)\)，并在固定嵌入中重建右邻下型目标。在本目录运行 `python3 -B ch39-complex-target-neighbour-feasibility.py` 可复算。
