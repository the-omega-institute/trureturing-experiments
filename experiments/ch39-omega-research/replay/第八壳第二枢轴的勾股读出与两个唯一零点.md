# 第八壳第二枢轴的勾股读出与两个唯一零点

第八壳三条最短边的同步相干读出使用同一正系数对 $(u,v)$，其中 $u^2+v^2=1$。第二枢轴的四方向支撑指标 $S_3$ 在从 $(1,0)$ 到 $(0,1)$ 的整段上恰有两个零点。以 $t=v/(1+u)$ 为参数，第一处从正变负，第二处从负变正。二者各自经过零时，截取的三个最大绝对谱权的层号都保持固定。[连续弧读出的原始定义](第八壳三条贝伦德最短弧上的枢轴支撑判据.md) · [勾股取点与两个变号窗复算](ch39-eighth-rational-arc-signs.py)

| $(u,v)$ | $t$ | 第二枢轴 $S_3$ 的外包闭区间 |
| --- | ---: | ---: |
| $(3/5,4/5)$ | $1/2$ | $[0.3188073,0.3188077]$ |
| $(5/13,12/13)$ | $2/3$ | $[-0.8315846,-0.8315842]$ |
| $(7/25,24/25)$ | $3/4$ | $[0.2834355,0.2834359]$ |

对每个有理 $t$，直接代入 $u=(1-t^2)/(1+t^2)$、$v=2t/(1+t^2)$，无需计算读出角、弧长或圆周率。每层权是 $1,u,v,u^2-v^2,2uv$ 的固定实线性组合。在这个取点步骤中，有理性属于读出系数。谱投影仍来自编号 $2\,306\,888\,100\,093$ 的实际黎曼零点高度、十九个整数站位及荷六磁拉普拉斯，Cholesky 行来自原算术 Gram 矩阵。单层响应仍使用原匹配能标、门户、角核和规范归一化。复算继续以 Arb 向外包围这些输入与最终指标。[谱权和支撑界的构造](ch39-eighth-shortest-arc-pivot-support.py)

## 整段符号与截取的三个谱权

下表所有十进小数均表示精确有理数。为每个参数区间包围各层权，逐一纳入可能取得前三名的层组合，再在 $20^3$ 个截止粗盒上运行原四方向极小极大。三个定号区间依次用 117、138、216 个闭段覆盖。

| 半角有理参数 $t$ 的范围 | $S_3$ |
| --- | --- |
| $[0,0.60328]$ | 严格为正 |
| $(0.60328,0.60330)$ | 严格下降，恰有一个零点，前三层为 $\{1,16,17\}$ |
| $[0.60330,0.73615]$ | 严格为负 |
| $(0.73615,0.73617)$ | 严格上升，恰有一个零点，前三层为 $\{1,8,17\}$ |
| $[0.73617,1]$ | 严格为正 |

两个变号窗内，第三与第四大绝对权各有严格间隙，十九个谱权的符号也各自固定。三层截断由第 16 层改为第 8 层的成员变化发生在两次过零之间，届时整个参数段已由负界覆盖。每个变号窗本身的零点都是同一三层组合之内的变化。

## 为何每个窗口只有一个零点

给定前三层及十九个权的符号，每个粗盒、每个支撑方向的有向下界都是各权的仿射函数。程序先对每个候选项计算值域。若某盒四个方向中最大值的下界已高于所有盒的最小上界，便可将它排除。对留下的盒，若某方向的上界低于本盒方向最大值的下界，也可将它排除。余下的项覆盖窗中每处实现极小极大的所有可能分支。

用 $u'=-4t/(1+t^2)^2$、$v'=2(1-t^2)/(1+t^2)^2$ 对余下的每个分支直接求导。首窗所有这些分支的斜率都小于 $-3.91738$，末窗斜率都大于 $3.62252$。有限个同向严格单调函数取逐点最大或最小值，仍有同一方向的斜率界。两窗内的指标连续，结合窗两端的异号，分别得到唯一的零点。可在复算目录运行 `python3 -B ch39-eighth-rational-arc-signs.py`。

三个勾股单位向量决定观测权。正指标在三个规范端点成立时强制中间能标的色逆耦合为负；负指标只说明四方向判据未触发。判定原生谱输运所需的两层转动数还涉及源谱截止与端点等式。[原生端点与全程分类](第八壳三个枢轴的端点与全程分类.md)
