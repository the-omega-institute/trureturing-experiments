# 同一组 Wilson 面权可以保留哪些奇荷迹

在第 $2\,306\,888\,100\,085$ 个零点处，令 $T_q=\operatorname{tr}L_q$、$S_q=\operatorname{tr}(L_q^2)$。原生电导与荷无关，故原生的两个矩分别记作 $T_0,S_0$。在十九点图的 529 个三角面上任选共用实系数，要求六荷的 135 条边各自严格正，并把荷二、四、六的一阶迹固定为十六条重支加三条轻支的规定总和。标准物质多重态的荷是 $(1,4,2,3,6)$，其中有两个奇荷；荷五提供了独立的第三个检验。

| 奇荷条件 | 全部 $27^3$ 种轻根组合下的结论 |
| --- | --- |
| $T_1=T_0$ | 可行。可逐条保留荷一的 135 条原生边电导，从而保留荷一的算子、全谱及所有矩。 |
| $T_1=T_3=T_0$ | 可行。另可同时精确保留 $S_1=S_3=S_0$。只固定这两个一阶迹时，第五荷迹比 $T_5/T_0$ 在参考轻根下的下确界在 $(8.80851160,8.80854735)$ 内。遍历全部轻根组合的全局下确界在 $(8.16269502,8.16273069)$ 内。 |
| $T_1=T_3=T_5=T_0$ | 不可行。所有符合前两个迹条件的构造均有 $T_5>8.16269502T_0$。 |

两个下确界的上界各由一组严格正电导达到所需精度。全局上界选取三个偶荷都取最小总迹的离散轻根组合。上述两类可行性分别有八个目标盒角点的严格正见证。任一目标是角点的凸组合，以相同权重组合同类见证的 529 个面系数，即得该目标全部六荷的严格正电导。固定参考轻根另存独立见证。此计算约束偶荷一阶迹，逐个偶荷本征值属于不同的逆谱条件。

每条边的正电导为 $w_e$，每个顶点的加权度为 $d_i$，磁相位在二阶迹中消去，故
$$
S_q=\sum_{i=1}^{19}d_i^2+2\sum_{e=1}^{135}w_e^2
\;\ge\; \left(\frac1{19}+\frac1{270}\right)T_q^2 .
$$
所有保留前两个奇荷迹的构造都有 $S_5/S_0>63.78489$；固定参考轻根时有 $S_5/S_0>74.27724$。在逼近固定分支第五荷迹下确界的一个严格正见证中，$(S_1,S_3,S_5)/S_0$ 分别约为 $(2.72722207,2.19379451,143.17113728)$。

另一族见证使荷一、荷三各自的一阶与二阶矩同时等于原值，并且对全部轻根组合均有效。在一组参考角点上，先精确满足五个线性迹条件，再沿其核内两个方向求解两个原生二阶矩方程。两式写成 $c+Dt+H(t,t)=0$ 后，区间计算给出 $-D^{-1}(c+H(t,t))$ 把半径 $10^{-7}$ 的二维闭盒映入半径 $1.18\times10^{-9}$ 的同心盒。Brouwer 不动点定理给出同时满足两式的精确点。对八个偶荷目标角点，在 90 个奇荷边轨道电导保持该点取值的同时，解三条偶荷迹等式。每个角点都得到由严格正性验证的 93 行可逆子系统解。组合同类角点系数始终保持这同一组奇荷边电导，故连续目标盒全域都保留这四个矩。这一族的全部边电导比均超过 $0.05428$，第五荷一阶迹比介于 $10.51252$ 与 $11.38481$ 之间。

## 全部自由面上的界

坐标轮换保持边的原生权和每个面的六个实 Wilson 因子。对任一可行解在三次轮换下平均，逐荷保持总迹与严格正性，得到在 179 个面轨道上常值的可行解。因此线性的可行性和第五荷迹下界覆盖原来的 529 个独立系数。对称面权给出 $270\times179$ 的响应矩阵 $B$，其中每荷有 45 个边轨道。证书选出 177 个列、177 个行组成可逆子矩阵 $A=B_{R,C}$。其余两列中，第 111 列的相位是 $+1$，响应为零。第 171 列所在的七个带号列组合各自对应一个共同相位，各组合的带号入射次数均沿第 35 与 40 个边轨道之差。因此七个向量属于一个六维空间。不含第 171 列的六个组合支撑不交且属于独立列，故张成这个空间，第 171 列可由已选列表示。索引从零开始。代码以整数相位标签及整数入射次数逐项检验这些事实。

令 $U=B_{:,C}A^{-1}$。任一对称响应精确等于 $Ux$，其中 $x$ 是 177 条主元边上的相对电导增量。原 529 个面上的见证系数由 $A^{-1}x$ 填入入选面轨道，其余面轨道赋零。证书以有理数种子和线性方程的可逆子系统定义 $x$，精确满足规定总迹。区间算术独立圈定各实际边的电导并与相应主元坐标表达式取交。

令 $L_qx=T_q/T_0-1$，把荷一、三、二、四、六的行依次叠为 $K$，其目标为 $b$。给定证书中的有理乘子 $y,\mu$，其中 $\mu\ge0$，置 $r=L_5-y^\mathsf{T}K-\mu^\mathsf{T}U$。若 $T_5\le10T_0$，六荷的正性与迹上界给出 $\lVert x\rVert_\infty<500$。于是
$$
T_5/T_0\ge 1+\min_b y^\mathsf{T}b-\sum_i\mu_i-500\,\lVert r\rVert_1.
$$
目标盒上仿射函数的最小值由八个角点给出。区间计算分别圈定了固定轻根与整个盒子的对偶残差一范数，均小于 $1.69\times10^{-10}$。若 $T_5>10T_0$，上述报告的下界直接成立。

有 Python 与 python-flint 时，可从复算目录运行以下命令。

```sh
python3 -B ch39-wilson-odd-preservation.py
```

运行后可读出固定轻根和八个角点的逐项区间。[见证与对偶乘子](ch39-wilson-odd-preservation.json)
