# 六层无原点三元流在第四壳的全部质量判定

冻结前两步的联合见证 \(X,Y\)。依照《OMEGA MATH》第四章的无原点三元运算，只取两个叶子 \(X,Y\)，每个内节点取 \([a,b,c]=ab^*c\)，以从根到最深叶子的边数为表达式深度。本实验在 \(N+4\) 逐项检验深度不超过六的所有根作为第三步发生元时的六个夸克质量窗。每个质量允许单独选择四站三平面。[前两步联合见证](相邻两壳以两个共同生成元连续实现完整CKM与荷六三读数.md)

令 \(A=YX^*\)，在证明中用 \(Y\) 写出这条陪集。两个叶子分别是 \(X=A^{-1}Y\) 和 \(Y=A^0Y\)，而
\[
 [A^iY,A^jY,A^kY]=A^{i-j+k}Y.
\]
若深度至多 \(d\) 的指数集是完整整数区间 \([a,b]\)，则三棵子树可独立选取，得到区间 \([2a-b,2b-a]\) 内的**每个**整数。该区间包含 \([a,b]\)，因此也覆盖更浅的树。初值为 \([-1,0]\)，端点和始终为 \(-1\)，端点差每层乘三。由此深度至多 \(d\) 时，
\[
 k\in\left[-\frac{3^d+1}{2},\frac{3^d-1}{2}\right]\cap\mathbb Z.
\]
在 \(d=6\) 恰有 730 个形式指数，从 \(-365\) 至 \(364\)。同一指数的表达式在任意这对酉矩阵上恒等，枚举指数等价于检验全部树。

## 四个质量在整族上出窗

对每个指数以 \(Z=A^kY\) 作第三步，在 \(N+4\) 的实际荷谱上读取 \(Z^{-2}Y^{-2}X^{-2}\) 与 \(ZYX\) 的四站算子。若其升序本征值为 \(\lambda_1,\ldots,\lambda_4\)，则在任意复三维子空间上，第 \(j\) 个质量的完整可达区间为 \([\lambda_j,\lambda_{j+1}]\)。下表的“可达”按单个质量和单个指数判定，涵盖上游完整联合参数盒。[参考窗](ch39-three-shell-outer-holdout.py) · [730 个指数的区间复算](ch39-fourth-ternary-depth-six.py)

| 夸克 | 排除指数数 | 单项可达的指数 | 整族质量严格下界（排除全部指数的四项） | 参考窗上沿 |
| --- | ---: | --- | ---: | ---: |
| \(u\) | 730 | 无 | 0.00249696 | 0.00000629 |
| \(c\) | 730 | 无 | 0.02534195 | 0.00316 |
| \(t\) | 729 | \(0\) | — | 0.8659 |
| \(d\) | 730 | 无 | 0.0002601088 | 0.0000137 |
| \(s\) | 730 | 无 | 0.0018687989 | 0.000271 |
| \(b\) | 729 | \(0\) | — | 0.01410 |

取 \(k=0\) 即沿用 \(Y\)，顶、底参考窗分别有适当三平面可达。其余 729 个指数各自排除全部六窗。四条整族下界都来自 \(k=0\) 的四站谱下端点。

计算以两个 Cayley 中心矩阵 \(X_c,Y_c\) 及各参数实际向外舍入半宽得到算子误差 \(\epsilon_X,\epsilon_Y\)。因这些矩阵酉，\(Z_c=(Y_cX_c^*)^kY_c\) 满足
\[
 \|Z-Z_c\|\le |k|(\epsilon_X+\epsilon_Y)+\epsilon_Y.
\]
这对负指数也成立，因为取伴随保持算子距离。若 \(p=2,1\) 分别对应上、下型，则三步累计输运的算子误差至多为 \(p(\epsilon_X+\epsilon_Y+\|Z-Z_c\|)\)。把训练源算子平移其谱中点，酉共轭的误差即以累计输运误差乘训练谱极差为界。末壳去相干和四站压缩均保持该误差上界。程序在每个指数分别比较相邻有序本征值的外包与原窗口的两个边界。在本目录运行 `python3 -B ch39-fourth-ternary-depth-six.py` 可复算两步联合证书、深度递推和全部单项判定。
