# 五枚连续编号的三空间下界在十维味参数邻域内稳定

取 \(N=2\,306\,888\,100\,085\)，用 \(p=(y_u,y_c,y_t,y_d,y_s,y_b,\theta_{12},\theta_{23},\theta_{13},\delta)\) 表示 1 TeV 的六个正 Yukawa 耦合与标准参数化的四个 CKM 参数。下表给出十个中心 \(c_i\) 及各自的边际半宽 \(s_i\)，角度均用弧度。[1 TeV 原表 2](https://arxiv.org/html/2510.01312v2#Sx1.T2)

| 参数 | 中心 \(c_i\) | 半宽 \(s_i\) |
| --- | ---: | ---: |
| \(y_u\) | 0.00000615 | 0.00000014 |
| \(y_c\) | 0.00311 | 0.00005 |
| \(y_t\) | 0.8616 | 0.0043 |
| \(y_d\) | 0.0000135 | 0.0000002 |
| \(y_s\) | 0.000268 | 0.000003 |
| \(y_b\) | 0.01401 | 0.00009 |
| \(\theta_{12}\) | 0.22704 | 0.00082 |
| \(\theta_{23}\) | 0.04275 | 0.00042 |
| \(\theta_{13}\) | 0.00377 | 0.00008 |
| \(\delta\) | 1.139 | 0.023 |

若每一枚的目标参数都满足

\[
 \max_{1\le i\le 10}\frac{|p_i-c_i|}{s_i}\le 10^{-6},
\]

则在 \(N-2,\ldots,N+2\) 同时实现这些夸克数据至少需要三个不同的四站复超平面。三个编号 \(N-2,N-1,N\) 可以各自选择盒内不同的十元组、独立的共同弱基及两荷各自的十九个 \([0,1]\) 谱振幅。将上式改为严格小于号即得所求的开邻域。完整十维边际 \(1\sigma\) 盒对应半径 \(1\)，该盒上的下界仍待确定。中心点的三个空间另有精确构造。[中心构造与对应原生层](五枚连续编号精确需要三个四站夸克味空间.md)

对整盒的输入计算 \(D_u=\operatorname{diag}(y_u,y_c,y_t)\)、\(D_d=\operatorname{diag}(y_d,y_s,y_b)\) 及 CKM 矩阵 \(V\)。以两部门各自的第三个耦合归一化，得到 \(A=V^*D_uV/y_t\)、\(B=D_d/y_b\)。整盒上质量有序、九个 CKM 元均非零、有符号 Jarlskog 不变量为正，且 \(\det[A,B]\ne0\)。两张图 \(A+tB, B+tA\) 的 \(-1\le t\le1\) 各覆盖三条本征线。每个区间中点以 Arb 的 Rump 算法包围整个输入盒的本征值与本征矢，再用 Gershgorin 圆盘和二阶子式的线性方程包围该支在整个铅笔区间中的方向。对任意固定输入，沿 \(t\) 的本征矢导数给出矩阵元的中值界。计算这些导数和尺度多边形时，同样使用整盒的 \(V\)、两荷质量和重味比值。[十维盒复算](ch39-five-shell-flavor-robustness.py) · [区间本征线](ch39-neighbour-all-frame-support.py) · [矩阵元导数](ch39-centered-observable-pencil.py)

同一超平面决定一个共同的原生单位方向 \(H\)。对每一枚分别检验其原生谱支撑，所选层射线均落在 \(H\) 的弦长 \(0.225\) 内。\(N-2,N-1,N\) 允许的层序依次为 \(\{1,7,10,16,18\}\)、\(\{16,18\}\)、\(\{7,10,16,18\}\)。在 \(N-2\) 的第 7、10 层还要求 \(H_x>-0.30\)，在 \(N\) 的第 7 层要求 \(H_x<-0.32\)。三对编号中，除 \(N-2,N\) 的层对 \((7,7),(10,7)\) 外，任一允许层对的固定弦长均大于 \(0.450\)。两个例外层对分别受上述互斥的有向坐标约束。由此，三枚编号两两不能共享超平面。[层对距离、方位角覆盖及有向坐标](ch39-five-shell-oriented-axis-triangle.py)

在本目录运行 `python3 -B ch39-five-shell-flavor-robustness.py` 可复算联合盒。六条本征支共检验 8092 个铅笔区间，其中 4049 个叶区间完成覆盖，最深二分 13 层。[复算程序](ch39-five-shell-flavor-robustness.py)
