# 与钟无关的十九站原壳谱宽上界

在十九站原磁拉普拉斯上，让两只钟的相位独立绕行整圈，并取软边亏额 $0\le\delta\le10^{-8}$。对荷 $q=1,-4,2,-3,6$，有
\[
 0.03403<\lambda_{\min}(H_q)\le\lambda_{\max}(H_q)\le36,
 \qquad \lambda_{\max}(H_q)/\lambda_{\min}(H_q)<1058 .
\]
因此若所有截止能量平方服从同一个标尺 $Q_j^2=\kappa\lambda_j$，$\kappa>0$，就有 $Q_{\max}/Q_{\min}<32.53$。选用部分谱层、删掉零权层或将相同位置的权重合并，只能缩小支撑的跨度。[原磁拉普拉斯](ch39-three-ray-chiral-boundary.py) · [逐荷区间证书](ch39-native-clock-independent-bandwidth.py)

## 一个不带钟的三角形

极点 $P=14$ 有十八条辐边，磁相位都为一。三角形 $14\to0\to16\to14$ 的另一条边平方弦长为 $632$，其原相位记为 $z$。每种荷的闭路相位为 $z^q$ 或其共轭，取决于读向。用原几何输入计算有 $d_q=|1-z^q|>0.0868$，该量与双钟始终无关。

写 $a=1-10^{-8}$，$E=\langle v,H_qv\rangle$。沿三角形依次搬运振幅，用三项 Cauchy–Schwarz 不等式，得到 $d_q|v_P|\le\sqrt{3E/a}$。另一方面，十八条辐边给 $\|v-v_P\mathbf1\|^2\le E/a$。于是
\[
 \|v\|\le\|v-v_P\mathbf1\|+\sqrt{19}|v_P|
       \le (1+\sqrt{57}/d_q)\sqrt{E/a}.
\]
这已经给出一个严格正的全钟谱底。对上端，将每条边的能量用两端模方之和的两倍控制。原边权不超过一，最大顶点度为十八，故 $E\le36\|v\|^2$。仅用这个三角形与全部辐边，下述脚本已验证五荷共同满足 $\lambda_{\max}/\lambda_{\min}<279000$。

## 保留所有不带钟的边

直接删除十二条带钟边，并把三条软辐边都降至权重 $a$。所得固定的 $123$ 边厄米算子记为 $K_q$。完整壳加回的每条磁边及权重增量都是正半定秩一项。因此 $H_q\succeq K_q$，全参数域内同时有 $\lambda_{\min}(H_q)\ge\lambda_{\min}(K_q)$。计算一次固定矩阵的全部谱即可核验每一行，表中两列分别向下、向上保守取值。

| 荷 $q$ | 原壳 $\lambda_{\min}$ 严格下界 | 原壳 $\lambda_{\max}/\lambda_{\min}$ 严格上界 |
| ---: | ---: | ---: |
| $1$ | 1.10965499 | 32.443 |
| $-4$ | 0.13529656 | 266.083 |
| $2$ | 0.03403338 | 1057.785 |
| $-3$ | 1.17047188 | 30.757 |
| $6$ | 0.30130225 | 119.482 |

运行 `python3 -B ch39-native-clock-independent-bandwidth.py`。接口 `spectral_bounds(root)` 中的 `root` 为回放目录，返回按荷索引的谱底下界、谱顶上界和谱比上界。复算使用 $160$ 位 Arb，不需选取 ζ 零点编号。
