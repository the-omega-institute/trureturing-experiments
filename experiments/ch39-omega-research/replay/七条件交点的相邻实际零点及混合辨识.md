# 已选交点能区分相邻的真实零点吗

用 \(N=2\,306\,888\,100\,085\) 的七条件解，固定同一能标 \(M\)、门户强度 \(u\)、五个有符号权及所有低能输入。把形成十九态算子的 ζ 零点编号分别换为 \(N-1,N+1\)。每个编号重新取真实高度、软亏额、带荷重谱和原生三循环不变投影。以下是新读数减去 \(N\) 读数的区间；七条件解位于原来的整个矩形内。[七式与背景](同一电弱背景的七条件交点.md) · [盒内唯一性](七条件交点的局部唯一性与轻耦合灵敏度.md)

| 在电弱驻点的读数 | \(N-1\) 的位移 | \(N+1\) 的位移 |
| --- | ---: | ---: |
| 牛顿项 \(K\) | \((-6.07544,-6.07542)\times10^{-8}\) | \((1.05657,1.05658)\times10^{-7}\) |
| 真空项 \(W\) | \((-1.43663,-1.43662)\times10^{-8}\) | \((2.27663,2.27664)\times10^{-8}\) |
| 电磁—色差 \(A_{QQ}-(8/3)A_3\) | \((-0.0056,-0.0044)\) | \((0.0038,0.0042)\) |
| 势的曲率 \(U''(r)\) | \((-0.0010570,-0.0010568)\) | \((0.0011384,0.0011386)\) |
| 势的斜率 \(U'(r)\) | \((3.376,3.378)\times10^{-12}\) | \((-1.438,-1.437)\times10^{-12}\) |
| 混合动能与色差 \(A_{QT_3}-A_3\) | \((-0.0030,-0.0028)\) | \((0.0024,0.0036)\) |

五权的归一自动保留，余下六项均有非零偏差。斜率用 \(x(E_2(s/x)-1)=x\,\mathrm{expm1}(-s/x)-sE_1(s/x)\) 计算，三循环的符号总数在每个编号相同，故常数项精确消去。混合动能中原谱的差取自相应编号的全场减法。轻 \(W\) 项在两个编号完全一致，重标量门户修正的差用两个编号的 \(r\sum_j1/(z_j-r)\) 界相加、乘以权总变差及 \(1/(24\pi)\) 控制。引力、曲率及电磁—色差均先求各列的差，再对同一组权求和。

允许在这三枚编号间作非负概率平均。令两个邻点的总质量为 \(\eta\)；当 \(\eta>0\) 时，\(t\) 为其中分给 \(N+1\) 的比例。记邻点的引力位移分别为 \((k_\pm,w_\pm)\)。两项平均偏差为
\[
 \eta[(1-t)k_-+tk_+],\qquad \eta[(1-t)w_-+tw_+].
\]
两条仿射函数斜率均为正，且各自从负跨至正。其绝对值较大者的最小值在两者互为相反数处取得。精确最优比例及单位邻点质量的最低代价为
\[
 t_*=-\frac{k_-+w_-}{k_+-k_-+w_+-w_-},\qquad
 D_*=\frac{|k_-w_+-k_+w_-|}{k_+-k_-+w_+-w_-}.
\]
证书给出 \(0.36906<t_*<0.36907,\ 6.6196\times10^{-10}<D_*<6.6200\times10^{-10}\)。因此在这三个候选编号上，若两项引力读数都要精确保持，全部概率必须落在 \(N\)。若两项绝对误差均至多 \(e\)，允许的邻点总质量至多 \(e/D_*\)。这里平均的是各个高度的模型读数。[实际零点及误差的区间复算](ch39-neighbour-seven-conditions.py)
