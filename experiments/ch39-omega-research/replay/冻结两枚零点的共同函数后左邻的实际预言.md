# 冻结两枚零点的共同函数后左邻的实际预言

取 $N=2\,306\,888\,100\,085$。在 $N,N+1$ 的三荷 $114$ 个节点上固定已校准的谱振幅，并固定已发表的平方倒距离加权公式及两点共用的四站复味空间。在 $N-1$ 上直接运行这套模型，荷六十九个截止仍处在电弱与普朗克能标之间，牛顿项却落在负侧。左邻的顶、底质量还分别越过参考窗的下、上两端，即使另选四站内的任意三代空间也无法修复。[双零点的共同函数](两个相邻零点同时匹配夸克与引力及左邻的弱差障碍.md) · [实际留出证书](ch39-frozen-pair-left-shell.py)

对于左邻任一实际谱点 $t$，三枚壳的节点互异，原有理式可直接写为
$$
R(t)=\frac{\sum_i w_i/(t-t_i)^2}{\sum_i1/(t-t_i)^2}.
$$
两枚校准壳提供全部 $t_i,w_i$。左邻的谱点和原生谱投影直接取自自己的磁拉普拉斯。计算用同一 $1$ TeV 场表及门户约定重建编号依赖的重谱。

| 左邻读数 | 冻结函数和味空间所得近似值 |
| --- | --- |
| 上型三个汤川耦合 | 0.01913080、0.07039928、0.23845235 |
| 下型三个汤川耦合 | 0.01639603、0.11033476、0.64353212 |
| $s_{12},s_{23},s_{13}$ | 0.99999678、0.99999834、0.89416774 |
| 有符号的 $J$ | $7.76\times10^{-7}$ |
| 荷六最低、最高截止 | $8.09308\times10^{10}$、$8.71666\times10^{18}$ GeV |
| 牛顿项 $K$、真空项 $W$、弱差 $D$ | $-0.43577362$、$0.99096965$、$-0.07425658$ |

任取四站内的复三维空间，单部门的最大压缩振幅位于四站算子的第二大与最大本征值之间。端值分别由三个最低本征方向的张成空间及任一包含最高本征方向的三平面达到。于是左邻的上型最重振幅至多约 $0.25172467$，下型最重振幅至少约 $0.15844021$。这两条必要界即使两个部门各选自己的空间也同时适用。

若把原轻顶质量替换为相应三平面给出的质量，牛顿项的变化仍小于 $10^{-30}$。记顶质量平方的无量纲值为 $z$、截止平方为 $x$，有 $\partial_z[x E_2(z/x)]=-E_1(z/x)$，且对 $s>0$ 有 $E_1(s)\le1+\max(0,-\log s)$。对每层使用上界、乘该层首枢轴权的绝对值再求和，即可覆盖所有三平面的反馈。$W,D$ 的表值保留既定轻场输入。

可以换一个在相同 $114$ 个校准节点取同值的共同函数，使左邻振幅改变。该实验固定了具体函数，因此检验的是它给出的第三点预言。[允许重选函数时的自由度](固定两个零点后第三个零点的有界谱振幅可任意指定.md)
