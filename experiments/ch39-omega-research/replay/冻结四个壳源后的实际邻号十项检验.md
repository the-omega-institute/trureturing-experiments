# 冻结四个壳源后的实际邻号十项检验

在上、下型零点编号 $(2345666,964890)$ 得到四个中央源协方差后，保留同一源与部门标尺，将两个制备零点各向后移动一枚至 $(2345667,964891)$。四个源在邻号上各有十项读数越出原 1 TeV 参考窗，包括六个质量、三个 CKM 混合角和带号 CKM 相位。以各项参考半宽计，按中央根的第一相位递增排列，每个源最接近参考中心的一项仍有如下偏差。[邻号区间复算](ch39-shell-commutator-next-zeros.py)

| 中央根的第一相位（弧度，约） | 邻号上十项偏差绝对值中的最小值（参考半宽） |
| ---: | --- |
| 1.657056 | $(41.69,41.70)$ |
| 2.130443 | $(9.92,9.93)$ |
| 5.058382 | $(42.05,42.06)$ |
| 5.450512 | $(15.00,15.01)$ |

这里的源来自壳坐标三循环 $H=iF^*(R-R^*)F$ 与压缩极点投影 $P=vv^*$。在 $B=[v,Hv,H^2v]$ 规定的实结构中，允许任意实对称源分量以及一个虚方向 $C=i[H,P]$。中央目标是原 $K_0$ 在中央零点对和原标尺下产生的精确十项读数，它们全部落入参考窗内。对四个解分别取 $S=MM^*$，写 $Y_q=s_qA_qM$，保持 $s_u=7.06539940386823251,\ s_d=1$。任意另一可逆因子 $M'$ 若有 $M'M'^*=S$，必与 $M$ 相差一个右酉因子。这同时酉共轭两部门的右 Gram 矩阵，所以质量和带号 CKM 读数相同。转到邻号时仅按新高度重算制备 $A_u,A_d$，这样所得偏差确实只依赖所冻结的协方差。[壳算子与中央校准源](ch39-shell-cycle-critical-sources.py) · [原标尺与十项读出](ch39-two-zero-quark-window.py)

若允许在邻号上重选共同可逆源及两个正部门标尺，仍无法同时进入原十窗。共同源从 $Y_uY_d^{-1}=(s_u/s_d)A_uA_d^{-1}$ 中消去，整体标尺之比也从相邻奇异值比中消去。写 $a<b<c$ 为 $A_uA_d^{-1}$ 的三个奇异值，则邻号给出 $3.06771<b/a<3.06772$ 和 $1.72654<c/b<1.72655$。完整十窗分别要求 $b/a>77.12$ 与 $c/b>61.32$。[参考窗所需的奇异值间隔](ch39-moving-preparation-quark-shape.py)

另一项检验在每对零点上分别以**该对**的 $K_0$ 和原标尺产生的十项为精确目标。对 $S(x,y)=M(x,y)M(x,y)^*$ 的完整两相位轨道，令 $z(S)$ 为 $B^*SB$ 三个上三角元素的虚部。上述源族等价于 $z(S)$ 与 $z(C)$ 共线，得到两个实方程。在各候选根盒验证压缩自映，并用区间四分覆盖整个环面，中央对和邻号对分别有 196 和 202 个终格。所得不同协方差的数量分别为四和二。按第一相位递增，中央四个 $\operatorname{tr}(CS)$ 的符号依次为负、正、负、正，邻号两个的符号依次为正、负。这里每对的精确目标均使用固定的两个原标尺，源由该组十项校准。[完整两相位轨道](固定两零点十项读数的两相位轨道与最小条件数.md)

## 中央四解的带号强度

在固定的壳三循环取向和原源标尺下，写 $S=S_{\mathrm{even}}+\lambda C$，其中 $C=i[H,P]$。按上表顺序，四个 $\lambda$ 分别落在 $(-0.00500681,-0.00500679)$、$(0.03448134,0.03448136)$、$(-0.04553798,-0.04553796)$、$(0.02552233,0.02552235)$。数值由四个唯一根的区间包围及 $\operatorname{Im}(v^*SHv)/\operatorname{Im}(v^*CHv)$ 直接得出。换用无量纲读数 $\lambda\,\|C\|_F/(\sqrt2\,\operatorname{tr} S)$，四支约为 $-0.201063,1.534918,-3.105909,1.541103$ 个百万分点。原标尺下单位带号系数两种取向均排除。规定符号可把四组缩至两组。[四个带号区间与归一化读数](ch39-shell-cycle-critical-sources.py)

循环向量 $v$ 确定一个反酉对合 $J$，它逐个固定 $v,Hv,H^2v$。三列张成整个空间，且 Gram 矩阵为实，故这样的 $J$ 存在且唯一。$JHJ^{-1}=H$、$JPJ^{-1}=P$、$JCJ^{-1}=-C$，于是 $S_{\mathrm{even}}=(S+JSJ^{-1})/2$。每个 $S$ 都正定，其实部也正定。若作用量和允许的协方差域均保持 $J$，唯一极小点必保持 $J$。中央四解的 $\lambda$ 全部非零，且绝对值两两不同；每解的反酉伙伴均离开这四个精确解。为从四解中选择一解，仍需给出独立的作用量条件。

在中央精确十项目标的整个两相位环面上，还有定量约束。对 $L=aH+bP+cC$、$(a,b,c)\ne0$，有 $\|[L,S]\|_F>0.0006\,\operatorname{tr}S\sqrt{a^2+b^2+c^2}$。以 $1000C$ 为第三个基元时，常数可取 $0.15$。将三个交换子在九个正交厄米方向上展开，取列 Gram 阵，减去相应系数度量乘以阈值平方。在整个校准环面上，区间 Schur 补检验严格正定。全质量窗的排除另由独立的迹比证书给出。[交换子区间证书](ch39-shell-cycle-critical-sources.py) · [完整质量窗](六个夸克质量排除全部壳三循环与极点的实厄米铅笔谱源.md)
