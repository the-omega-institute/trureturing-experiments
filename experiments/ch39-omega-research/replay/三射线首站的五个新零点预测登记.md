# 在五个新零点上预先指定读弱的荷

待检验量为原十九站磁拉普拉斯最低三态在三条射线首站 $\{6,7,8\}$ 上的限制最小奇异值。五个编号均超过一百万。本次根据真实高度的两钟相位选择编号，选取时没有计算这五个高度的轻带或读取待检验量。此前研究已使用其他零点的谱并找出每荷的环面盲点。

| 正零点编号 | 预测唯一读弱的荷 |
| ---: | ---: |
| 1632060 | 1 |
| 2086602 | −4 |
| 2040244 | 2 |
| 1856372 | −3 |
| 2010251 | 6 |

逐行预测所列荷的最小奇异值严格小于 $0.001$，其余四荷均严格大于 $0.001$。五行与阈值在公开验算前冻结。任一预报的荷超出阈值，就记该行失败。任一严格比较无法由区间分离，则记未判定。十个荷对的共同背景证书已说明至多一荷能低至该阈值，因此每行中额外要检验的是指定荷是否实际达到它。

选取编号时，先按每荷盲点盒心和已知钟速率寻找两个相位接近的高度窗，以正零点计数定位窗内编号，再只以真实高度核对两个有效相位到各自盒心的弦长均小于 $0.002$。没有对其他高度的命中率或指定编号的最小性提出预测。[只读取相位的登记核对](ch39-first-ray-forecast-phases.py) · [既有盲点盒心与证据](ch39-first-ray-light-zeros.py)
