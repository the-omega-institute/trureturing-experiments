# 十九点以后，平方弦长比 181/8 首次在哪些完整对角壳重现

在含对角整数点的完整非负八分体球壳中，最初的十九点相似类之后，平方弦长比 $181/8$ 首次在 **37 个点**时重现。恰有两个并列的相似类，半径平方分别为 $1875\cdot4^a$ 与 $4107\cdot4^a$，$a\ge0$。两者的对角点奇因子分别为 $25$ 和 $37$，均与 $17$ 互素。若在同点数下按奇因子从小到大排序，则首个为 $25$。

## 从点数得到有限枚举范围

记 $P_n=\{(x,y,z)\in\mathbb Z_{\ge0}^3:x^2+y^2+z^2=n\}$。含正对角点的壳有 $n=3(2^a u)^2$，其中 $u$ 为正奇数，$P_n=2^a P_{3u^2}$。写 $N(u)=|P_{3u^2}|$。由三平方表示数的局部因子公式，对每个 $p^k\parallel u$ 有
\[
  1+(p-\chi_{-3}(p))\sum_{j=0}^{k-1}p^j
  \ \ge\ 1+(p-1)\sum_{j=0}^{k-1}p^j=p^k.
\]
因而 $N(u)\ge u$，对给定的点数上界只需检验不超过它的正奇数。$P_0$ 只有一个点。[计数公式与十九点分类](ch39-nineteen-lattice-shells.py) · [Hirzebruch–Zagier，§1.2 与 §2.1](https://people.mpim-bonn.mpg.de/zagier/files/doi/10.1007/BF01390005/CurvesOnHMS.pdf)

以 37 为点数上界，逐一枚举 $1\le u\le37$ 的所有奇数。对每个整数 $0\le x\le\lfloor\sqrt{3u^2}\rfloor$ 及 $0\le y\le\lfloor\sqrt{3u^2-x^2}\rfloor$，检验 $3u^2-x^2-y^2$ 是否为完全平方数，可得全部点。在表中保留 $N(u)\le37$ 者，再对不同点形成的全部无序点对取平方距离。由于 $181$ 与 $8$ 互素，所有合格长短平方长度对均形如 $(181h,8h)$，$h$ 为正整数。

| ---: | --- | --- |
| 1 | 1 | |
| 4 | 3 | |
| 7 | 5，7 | |
| 13 | 9，11，13 | |
| 19 | 17，19 | 17 |
| 25 | 23 | |
| 28 | 15，21 | |

| 37 | 25，37 | 25，37 |

## 弦的端点与整壳副本

三个命中壳的唯一合格平方长度对均为 $(724,32)$。每壳都各有六条长弦和三条短弦。下表在每个原始尺度各取一例。

| $u$ | 平方长 724 的弦端点 | 平方长 32 的弦端点 |
| ---: | --- | --- |
| 17 | $(1,5,29),(13,23,13)$ | $(1,5,29),(5,1,29)$ |
| 25 | $(5,13,41),(17,31,25)$ | $(1,5,43),(5,1,43)$ |
| 37 | $(11,31,55),(23,47,37)$ | $(7,43,47),(7,47,43)$ |

在 $u=17$ 上，有六对长短弦共用一个端点，闭合三角形的第三边平方长均为 804。在两个 37 点壳内，六条长弦的端点集合与三条短弦的端点集合完全分离，因此不能由同一三角形给出这对长度。$u=25,37$ 的全部不同平方弦长数分别为 89 与 92，于是两壳彼此也不相似。[距离与端点穷举](ch39-next-lattice-shell-ratio.py)

还可以精确判定整壳副本。$P_{3u^2}$ 含 $P_{867}$ 的一个十九点相似副本，当且仅当 $17\mid u$。原壳包含四个仿射无关的点，故任一副本的外接球唯一，必与承载该副本的目标球重合。相似比因此为 $u/17$，原壳一条平方长 32 的弦变为平方长 $32u^2/17^2$ 的格点弦。该数为整数强迫 $17\mid u$。反之，$17\mid u$ 时直接按 $u/17$ 放缩原坐标，即得完整十九点副本。恢复因子 $2^a$ 同样保持这一判据。原十九点相似类以外，首个含完整副本的壳取 $u=51$，由局部公式得 $N(51)=4\cdot19=76$。更大的奇数倍 $u$ 至少为 85，已超过 76。

十九点的条件因此在两处起作用。它从所有完整非负八分体壳中强迫一个对角点，再与弦长比一起选出 $P_{867}$ 的相似类。在已给定对角点时，点数小于 37 的结论仍然成立。到了 37 点，两个新壳都能重现数比与两种弦的重数，而原壳的共端点三角关系仍可区分这三个候选。
