# 全部轻重场共用有符号截止的有限动量交汇

在第 \(N=2\,306\,888\,100\,085\) 枚实际 ζ 零点，采用电弱对称原点、三代轻场及十六重 Higgs 双重态。五个普朗克有界的正截止可以同时给出精确的 \(K=1, W=10^{-122}\) 与三支规范耦合的有限动量交汇。固定交汇能标 \(M_G=10^{16}\,\mathrm{GeV}\)，统一逆精细结构常数满足
\[
39.12824<\alpha_U^{-1}<39.12826.
\]
此前局域 \(a_4\) 处方对重场施加零动量阈值，再叠加轻场的标准对数跑动。本次从 \(M_Z\) 的实输入出发，轻场、重场和轻规范场的鬼贡献全部使用同一个截止作欧氏动量减法。

## 各场的动量减法

记 \(x=Q^2/M_P^2\)、\(p=P_E^2/M_P^2\)、\(p_0=M_Z^2/M_P^2\)、\(z=M_j^2/M_P^2\) 及 \(h=u(1-u)\)。对于单一截止，物种 \(j\) 从 \(p_0\) 至 \(p\) 的无量纲积分为
\[
 R_j(x;p)=\int_0^1 du\,\omega_j(u)
 \big[E_1((z+p_0h)/x)-E_1((z+ph)/x)\big],\qquad
 E_1(y)=\int_1^\infty e^{-yt}\frac{dt}{t}.
\]
四种角权均在 \([0,1]\) 归一。令 \(a=(1-2u)^2\)，则费米子权为 \(6h\)，标量权为 \(3a\)，重矢量权为 \((8-3a)/7\)，轻 Yang–Mills 规范场含鬼的权为 \((4-a)/(11/3)\)。当 \(z=0,h=0\) 时，方括号按连续延拓取 \(\log(p/p_0)\)。

在 \(M_Z\) 采用 \(\alpha_{\mathrm{em}}^{-1}=127.930\)、\(\sin^2\theta_W=0.23129\)、\(\alpha_s=0.1180\)，以大统一归一化给出三支逆耦合 \(a_i\)。轻部门含三代 Weyl 场、一个复标量双重态、含鬼的轻规范场，三类系数相加恰为 \((41/10,-19/6,-7)\)，其中规范场给 \((0,-22/3,-11)\)。重部门沿用实际谱，含五类各十六层 Dirac 场、荷 3 处的十六个复标量双重态与十八层重矢量。记每一物种的系数为 \(b_{ij}\)，定义
\[
 D_i(x;p)=-\frac1{4\pi}\sum_j b_{ij}R_j(x;p),\qquad
 A_i(p)=a_i+\sum_m c_mD_i(x_m;p).
\]
在 \(p=p_0\) 时所有减法项精确为零。用 \(M_P=1.22089\times10^{19}\,\mathrm{GeV}\) 转换输入动量与实际质量。

## 五个截止的精确解

取 \(p_G=M_G^2/M_P^2\)。五个截止位于 \(x_m=(4\times10^{-15},3.5\times10^{-11},1.23\times10^{-6},0.5,1)\)。将下列五个分量的列向量在五点组成方阵
\[
 V(x)=(1,K(x),W(x),D_1(x;p_G)-D_2(x;p_G),D_1(x;p_G)-D_3(x;p_G))^T .
\]
以 \(T=(1,1,10^{-122},a_2-a_1,a_3-a_1)^T\) 为目标，精确权重定义为方程 \(\sum_m c_mV(x_m)=T\) 的唯一解。认证行列式在 \((-819,-817)\) 内，五权的近似值为

| \(x_m\) | \(c_m\) |
| ---: | ---: |
| \(4\times10^{-15}\) | \(+0.136298\) |
| \(3.5\times10^{-11}\) | \(+0.580658\) |
| \(1.23\times10^{-6}\) | \(+1.381137\) |
| \(0.5\) | \(-1.464123843284\) |
| \(1\) | \(+0.366031075606\) |

尾函数由相应权重从右端累加，全部非零段的符号依次为正、正、正、负、正。因此 \(H\) 翻号两次。总负质量严格介于 \(1.4641238432\) 与 \(1.4641238434\) 之间。作为比较，单独拟合两项引力读数时已认证最优负质量大于 \(1.46412119952155\)，所以这个共同解距引力下界小于 \(2.644\times10^{-6}\)。共同拟合的原子数、翻号次数和负质量的最优值尚未确定。

## 角积分与整段跑动的认证

利用对称性只积 \([0,1/2]\)。截去最左端 \([0,2^{-m}]\)，在其余每个 \([l,2l]\) 二进小段作 \(n\) 点 Gauss–Legendre 积分。误差可由同一解析上界控制。对复数 \(u\) 改写核的方括号为
\[
 \int_{p_0}^p \frac{h}{z+th}\exp[-(z+th)/x],dt.
\]
在以 \(3l/2\) 为中心、半径 \(7l/5\) 的复圆盘上有 \(0<\Re u<1\)，所以 \(\Re h>0\)，\(|th/(z+th)|\leq1\)，各角权的模均小于 20。于是角权乘方括号的模至多为 \(20\log(p/p_0)\)。在积分段上用 \(2n-1\) 阶 Taylor 多项式逼近时，Cauchy 比为 \(5/14\)。Gauss 规则对此多项式精确，真实积分和正权求积各产生一份逼近余量。最左段在实轴上用 \(0\leq\omega_j\leq3\)。合并得到整个对称角积分误差至多
\[
 \log(p/p_0)\left(6\,2^{-m}+40\frac{(5/14)^{2n}}{1-5/14}\right).
\]
在交汇点取 \(n=14,m=41\)，每个角积分绝对误差小于 \(1.391\times10^{-9}\)。对已经指数压低的行也可直接使用 \(R_j\leq e^{-z/x}\log(p/p_0)\)。

三支逆耦合从 \(M_Z\) 到 \(M_G\) 的整段保持正值。单个物种在单个正截止下的 \(R_j\) 随 \(p\) 递增；把对数平方动量分成 28 段，正系数取左端、负系数取右端，即可检验每一段的严格下界。该检验用同一余项公式，取 \(n=7,m=17\)，三支逆耦合的全程下界依次超过 33.92、15.63、3.70。
