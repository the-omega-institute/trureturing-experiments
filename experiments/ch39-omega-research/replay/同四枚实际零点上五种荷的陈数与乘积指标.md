# 四枚实际零点的五荷面上链与两个球面上的四维指数

在十九站原壳的第 $9,4,16,10$ 枚实际正零点，依次将边 $(0,2),(5,14)$ 的电导设为 $(0.0005,27),(0.0005,27),(0.016,7),(0.0005,27)$。其余原边、两钟和三条软辐边均使用各高度的实值。将四个顶点的三维轻空间作行列式重叠，按主辐角填面，**标准模型五荷中只有荷 $-3$ 的第一陈数为一，其余四荷为零**。两份这样的球面作直积后，按整代标准模型重数逐分量作同荷外积，得到的 Dirac 指数为二。要在同一批有限数据上得到无迹的指数三，还可明确选取两条单位度线的张量幂和直和。[原四顶点荷 $-3$ 的读出](ch39-actual-zero-weyl-mesh.py)

## 面上的五组整数

取四面体边界定向 $(123),(032),(013),(021)$。以 $F_i$ 为最低三态的归一标架，让前三个站点的三行子式的行列式实正，确定顶点行列式线的相位。复算验证这二十个子式均非零。取 $U_{ij}=\det(F_j^*F_i)/|\det(F_j^*F_i)|$，对 $i<j$ 令 $A_{ij}=\operatorname{Arg} U_{ij}$，并令 $A_{ji}=-A_{ij}$。每个正向面的整数为
\[
 n_{ijk}=\frac{\operatorname{Arg}(U_{ij}U_{jk}U_{ki})-(A_{ij}+A_{jk}+A_{ki})}{2\pi}.
\]
表中的第三列为四个有向面依次所得的整上链。换顶点规范或边相位实提升可以加上整余边界。最后一列的求和消去了所有边项。

| 荷 | 六条边中的最小行列式模 | 四个面上的 $n$ | 度数 $d_q$ |
| ---: | ---: | --- | ---: |
| $1$ | $0.05878975\ldots$ | $(1,0,0,-1)$ | 0 |
| $-4$ | $0.43545941\ldots$ | $(0,0,0,0)$ | 0 |
| $2$ | $0.17707254\ldots$ | $(-1,0,0,1)$ | 0 |
| $-3$ | $0.30014194\ldots$ | $(0,0,0,1)$ | 1 |
| $6$ | $0.43058683\ldots$ | $(0,0,0,0)$ | 0 |

全部三十条边的重叠均非零，所有面均严格避开主值切口。224 位球算术逐面只包住所列的一个整数。以下以该整上链作线丛的绕数粘合数据，等价于在每个面选择所测的主值通量。记行列式线为 $L_q$，对应的秩三轻丛插值为 $E_q$。在 $S^2$ 上一个秩三复丛由行列式绕数完全确定，因为 $\pi_1(U(3))\to\pi_1(U(1))$ 为同构。故这里讨论的四维外积只需要表中的上同调类。[逐面相位与验算](ch39-finite-zero-product-index.py)

## 乘积的有限配对

在 $X=S^2\times S^2$ 上取两球的正向生成元 $x,y$，使 $x^2=y^2=0$、$\int_Xxy=1$。取 $A_q$ 为第一球的 $E_q$ 或 $L_q$，$B_r$ 为第二球的 $E_r$ 或 $L_r$，其秩记作 $s,t\in\{1,3\}$。四种取法的陈特征统一为
\[
 \operatorname{ch}(A_q\boxtimes B_r)=
 st+t d_q x+s d_r y+d_q d_r xy,\qquad c_2=(st-1)d_qd_r xy.
\]
乘积胞腔的十六个四维面的整配对为 $n^{(q)}_f n^{(r)}_g$，相加恰为 $d_qd_r$。$X$ 是自旋流形，$p_1(TX)=0$，故扭曲自旋 Dirac 的指数就是这一整数。按上表的荷次序，五乘五的指数表仅第 $(-3,-3)$ 项为一。对上述任一单独外积均有 $\operatorname{ch}_2=c_1^2/(2st)$，所以去掉迹部后的二次陈形式在四维的上同调配对为零。若采用两个球面的乘积联络，这一无迹二次形式的四维部分也逐点为零。

* 按五个荷类型各取一份同荷外积，指标为 $1$。计入左手账本 $(Q,u^c,d^c,L,e^c)$ 的弱、色重数 $(6,3,3,2,1)$ 后为 $2$，来自轻子双重态。若改为把第一球的物理左手与第二球的物理右手作 Hom 外积，指标因子为 $-d_Ld_R$。右手荷 $4,-2,-6$ 与表中对应荷的谱共轭，所以其度数均为零，这些左右配对均给零。
* 取第二球的实测单位度线 $L=L_{-3}$，让荷 $q$ 在其上用超荷幂 $L^q$，第一球仍取 $E_q$。单项的陈特征为 $3+d_qx+3qy+q d_qxy$。五类型各一份给指标 $-3$ 和 $c_1=x+6y$。改用 $L^{-q}$ 则给 $+3$ 和 $c_1=x-6y$。完整一代分别给 $-6,+6$，两种都有 $c_1=2x$，因为整代超荷和为零。单独取 $E_{-3}\boxtimes L^3$ 也给 $+3$ 和 $c_1=x+9y$，其指标全部由此迹部给出。

## 一个行列式恒一的指数三

如果允许明确指定额外的张量规则，取 $L_x,L_y$ 为来自两个球面的实测单位度线。对两个整数向量 $a,b$，令
\[
 V=\bigoplus_j L_x^{a_j}\otimes L_y^{b_j}.
\]
其 $c_1=(\sum a_j)x+(\sum b_j)y$，指数为 $a\cdot b$。取 $a=(1,-1,0)$、$b=(1,-2,1)$，得到行列式恒一的秩三丛，$\operatorname{ch}_2=3xy$、$c_2=-3xy$。用同一对线联络诱导各幂时，总曲率的迹逐点为零。在这种直和协议下，秩二且两向量和分别为零时指标必为偶数，故秩三已是实现三的最小秩。

若每份只许单位度、对偶或平凡线，即 $a_j,b_j\in\{-1,0,1\}$，最小秩为五。秩至多四且指标为三要求 $a$ 至少有三个非零项。和为零迫使恰有四项，两个正、两个负，此时 $a\cdot b$ 等于两个正位置的 $b$ 之和的两倍。秩五时 $a=(1,1,-1,-1,0)$、$b=(1,1,-1,0,-1)$ 即达三，而且总曲率的迹仍恒零。

这些四维指数使用两份实际零点四面体、指定面主值、乘积取向及所选的扭曲丛。四维自旋 Dirac 指标计算净零模数。把这项有限球面插值解释为物理四维 Weyl 家族，还需要指定时空算子、手征表示和动力学选择的张量规则。
