# 原生钟随高度转动时，两条正边权构成第一陈数为一的交点

在十九站原壳上取荷 $q=-3$，按同一连续高度 $h$ 代入原两钟及三条软辐边的亏额。只让原边 $(0,2)$ 和 $(5,14)$ 的正电导 $w_1,w_2$ 独立变化，原生相位照常搬运。第三、第四本征值在下列内点形成 Weyl 交叉。

| 参数 | 交点值 |
| --- | ---: |
| 高度 $h$ | $80.928425691033686017\ldots$ |
| $(0,2)$ 电导 $w_1$ | $0.01615054064436668415\ldots$ |
| $(5,14)$ 电导 $w_2$ | $11.16447955978410845\ldots$ |
| 重本征值 $E$ | $8.9293140820548336958\ldots$ |

在 $(h,w_1,w_2)$ 的标准定向下，取包围精确交点的外向小球面。采用 $c_1=(i/2\pi)\operatorname{Tr}(P\,dP\wedge dP)$，最低三维谱丛的第一陈数是 **$+1$**。半径可具体取 $10^{-13}$。交点高度严格位于第 21、22 枚实际正零点之间。此处连续插值的两个钟速和高度亏额都由原壳给定。[原生高度联络](ch39-three-ray-chiral-boundary.py) · [256 位区间复算](ch39-first-chern-edge.py)

## 两个实方程确定交点

记未调边的壳为 $H_0(h)$，两条边的原电导均为一，它们的平方弦长分别为 32 和 544，均不带钟。给边 $(i,j)$ 的未改相位 $u$ 配列向量 $b=e_i-\overline u e_j$。置 $B=(b_1,b_2)$、$T=\operatorname{diag}(w_1-1,w_2-1)$，新壳为 $H_0+BTB^*$。在 $E$ 避开原谱处令
\[
 V=(H_0-E)^{-1}B,\qquad G=B^*V .
\]
两列边向量独立，二重本征值等价于 $T^{-1}+G=0$，此时重本征空间为 $V$ 的列空间。先求复标量方程 $G_{12}=0$，再取 $w_j=1-1/G_{jj}$。以 $h=\gamma_{22}+s$ 参数化，令 $s_0=-1.98195516305233$、$E_0=8.92931408205483$。用中心二阶实雅可比的逆预乘方程，在半径 $10^{-11}$ 的 $(s,E)$ 盒上核对牛顿映射严格压缩并自映。再在一次中心修正后的半径 $10^{-25}$ 小盒重验；小盒包含在大盒内。导数由 $\partial_E G=V^*V$ 和 $\partial_hG=(\partial_h B)^*V+V^*\partial_hB -V^*(\partial_hH_0)V$ 直接得到。精确根处两实方程的雅可比行列式约为 $0.002202895435$。

原壳在该能量下恰有三个更低本征值。$T$ 一负一正，对增广厄米矩阵
\[
 \begin{pmatrix}H_0-E&B\\ B^*&-T^{-1}\end{pmatrix}
\]
分别沿左右两个对角块作 Schur 消元。左端消元后另一个块为零，右端消元后另一个块是新壳减 $E$。故新壳在重根下方恰有 $3-1=2$ 个本征值，交叉正是第三、第四带。[求根盒与正电导记录](ch39-first-chern-edge.py)

## 有向锥与球面陈数

把 $V$ 的两列依次正交归一得 $F$。对三个正向参数的导数，算 $M_j=F^*(\partial_jH)F$。其无迹部分在标准 Pauli 基中的列为 $(\Re(M_j)_{12},-\Im(M_j)_{12},((M_j)_{11}-(M_j)_{22})/2)$。三个列的有向行列式是 $3.45581325707\times10^{-5}$ 附近的严格正数。孤立二重簇在交点邻域光滑，任一与 $F$ 一致的局部正交标架给出的压缩矩阵，其交点一阶无迹项就是上述速度矩阵。因此归一化的三分量在小球面上的映射度为 $+1$。下支投影为 $(I-\widehat d\cdot\sigma)/2$，代入所定陈形式，其积分正好是这个映射度。更低两带的总投影延展过球心，其第一陈数为零。

在此高度附近每条钟边对高度的一阶算子范数至多 $|q|$ 乘该钟速；十二条钟边及三条软边加总小于 20。两条调权边各自的导数范数为 2。在距精确交点 $10^{-13}$ 的闭球中，第三、第四本征值由 Weyl 界至多移动 $24\times10^{-13}$，高度的移动至多 $10^{-13}$，均仍处于上述大求根盒中；区间计算在整盒中验证了原分辨算子存在。若球内另有第三、第四重根，它必须再解同一个 $G_{12}=0$，唯一性和两个对角方程会强制相同的三个参数。因此每个 $0<r\le10^{-13}$ 球面均可连续缩到更小的有隙球面，陈数一致。

**两条边的最少性限于此高度扫描规则。** 只给一条边时，独立参数为 $(h,w)$，有隙区域是实平面中的开集，其普通整系数二次上同调为零，任何闭曲面拉回的第一陈数都消失。若允许两钟作为独立相角变化，母空间有不同拓扑，这个单边最少性证明的适用范围随之改变。固定在实际第 22 枚高度时，任一单边的整个非负半轴已有统一谱隙。[第 22 枚的单边全权证书](ch39-one-edge-chern.py)
