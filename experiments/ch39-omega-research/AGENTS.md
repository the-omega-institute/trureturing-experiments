# 第 39 章统一问题研究

本项目的后续推理、证明、反例、数据和复算程序只在本公开仓库维护。更新本目录的研究地图与相关复算说明，保留模型前提与开放问题。待命任务优先使用完成通知或单次阻塞等待。

长期研究运行期间，以同时在跑的独立研究 CLI 子进程计数，主会话另计，至少维持 10 路。每一路收到完成通知就保存结果并接续可独立推进的问题。书稿审校、CI 与部署可同时进行。用户暂停或结束研究时停止接续。

需要更新下载包时，先用 Git 登记新增的复算文件，再运行本目录的 `python3 pack_replay.py`，将包与源文件一同提交。

实验提交直接推送至本公开仓库。若远端规则要求主分支必须通过 PR，直接推送公开研究分支并记录提交链接。
