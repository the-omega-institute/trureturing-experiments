# Direct field runtime

`field_graph.py` links finite bit/reference control graphs and a four-reference,
eight-bit finite reserve. Its generic LAB driver keeps old/intended heads,
arm, program references, growth continuations, real fresh material and each
ancestor append in actual registers. Generic program size, input length and
finite prefix length have no fixed bound; each finite run needs a sufficient
finite grant. The complete reserve is retained and counted from setup.

`primitive_engine.py` reads actual encoded opcode, selector, operand and
successor fields through resumable CPU phases. Operand locations are linked
references; compiler dictionaries and reference interpreters supply no runtime
instruction. Its finite phase/index updates and local selector implementation
are still compound operations. This is progress toward the literal ML-I engine,
not a claim that every single-bit intermediate cut has been realized.

`field_decoder.py` lowers the published register decoder to Boolean branches,
word snapshots, actual directory links and a complete page-field selector tree.
`execution_graph(height,361)` connects the unchanged full-image fetch format,
actual input conversion, the LAB driver and returned-head output scan. Its
numeric address bank concerns that fixed image only. Arbitrary finite generic
B programs use actual instruction/jump references instead.

`field_io.py` converts received chains through the actual stack serialization,
two-bit alphabet, copier records and NWMG encoding. Its output scan starts at
the actual returned active header and follows the source-binary head flag to
the actual output separator. It emits the decoded chain through occupied
latches and End/Ack/Return. The output sink is never an instruction or answer
source. Accepted arithmetic framing is A's unchanged premise.

The setup routines are host preparation. Their bulk coordinates and object
initializations are not a paid chronological installer. There is no complete
original-port Evaluate/Read/Predict/Close controller, received-frame parser,
cleanup or shared-job directory, dynamic width migration, or chronological
source/observer census. `session.records[-1]` and `Print.emitted` remain
operational on their existing paths. No audit label removes these consumers.

Run `field_checks.py --full --output field-results.json` and the same command
with `--check` for exact equality. `--mutation omit-code-reads` must reject with
`[FAIL] primitive_event_census`. `field_protocol_checks.py` takes its result path
and checks code mutation, pending output, forbidden acknowledgements and a
connected finite-image conversion/LAB prefix. The output fixtures and connected
prefix are component tests; neither is the complete law execution required by C.
The original exact suite retains both strict failures and `B_complete=false`.
