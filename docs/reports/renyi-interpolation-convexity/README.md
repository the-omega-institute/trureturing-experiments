# Rényi interpolation convexity check

This report checks Jiange Li's arXiv:1704.02634v2 Conjecture 3.2 family using exact rational arithmetic and SymPy identities. It verifies the uniform-disk projection density normalization, the quadratic projection scale, and the interior Jensen defect for correlation `rho = -1/2`. The script uses no floating point as evidence.

Run:

```text
python3 check.py
```

The final line must be `ALL_CHECKS_OK`.
