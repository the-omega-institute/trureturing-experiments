# Rényi information of ranked set samples

Run `python3 check.py` with Python 3.12 or later and SymPy. The stored output uses SymPy 1.14.0.

The fidelity check evaluates the $n=\alpha=2$ unit-rate exponential formulas in §3 of Jafari Jozani and Ahmadi. The refutation check integrates the squared rank densities for a Pareto parent in its quantile coordinate. The factorizations give the strict collision-product ordering throughout $1/2<p<3/4$, and the order-2 Rényi information reverses it. The program uses exact symbolic and rational arithmetic. [Source](https://arxiv.org/abs/1301.4292v1)
