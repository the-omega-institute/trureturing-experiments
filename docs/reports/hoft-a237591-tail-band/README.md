# Hoft A237591 tail-band check

`check.py` uses only integer arithmetic. It reproduces the first ten rows in
the OEIS A237591 entry, compares the consecutive-partition count with the
displayed ceiling formula for `n <= 150`, and checks that every pair in the
claimed band with `k <= 200` has value 1 or 2. The finite checks are supporting
evidence; the preregistration proposes the uniform ceiling argument as the
settlement route.
