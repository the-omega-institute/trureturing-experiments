# Eldar's OEIS A179875 conjecture: exact finite checks

Run `python3 docs/reports/eldar-a179875/check.py` from the repository root with Python 3. The program uses only the standard library, integer arithmetic and `fractions.Fraction`. Its output is stored in `check.out`; success ends with `ALL_CHECKS_OK` and exit code 0.

For every positive n through 2000, the program builds the reduced residue system by testing gcd directly, sums the first two powers and forms their exact rational quotient. Independent trial factorization supplies the radical and totient product; an Eratosthenes-style sieve supplies the Möbius function. It checks the classical moment formulas for n > 1, the n = 1 convention, the normalized moment and its sharp endpoint conditions, and all 1999 adjacent biconditionals. The direct means also reproduce all 43 displayed A179875 terms through 502 and the source example B(10) = B(11) = 7. These finite checks do not prove the unbounded conjecture.

Sources: Amiram Eldar's conjecture in [OEIS A179875, revision 13](https://oeis.org/A179875), and the reduced-residue definitions in [A053818](https://oeis.org/A053818), [A023896](https://oeis.org/A023896), [A175505](https://oeis.org/A175505) and [A175506](https://oeis.org/A175506); the sequence is by Jaroslav Krizek. The displayed sequence terms are attributed to the OEIS Foundation and contributors under the [OEIS End-User License Agreement](https://oeis.org/wiki/The_OEIS_End-User_License_Agreement). The classical first and second moments are quoted in Constantin M. Petridi, [arXiv:1612.07632v2](https://arxiv.org/abs/1612.07632v2), Section 1, which credits Pólya and Szegő for the second moment. Those formulas are ingredients, not claimed new results.
