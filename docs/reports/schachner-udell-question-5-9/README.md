# Schachner–Udell Question 5.9

Exact checks for Mark Schachner and Gabe Udell, *The group generated by a graph's derangements*, arXiv:2610.18463v1, Question 5.9.

Run `python3 check.py`; the Python 3 standard library is sufficient. `output.txt` contains its output. All evidence uses integer permutations and finite sets, with no floating point.

The fidelity checks reproduce Examples 1.2(i) for cycles C3 through C8, Proposition 2.2 for K2 through K6, and the C8 leap-group order 32 stated in the introduction and Corollary 2.7. They compare adjacency backtracking against enumeration of all permutations.

For each t from 0 through 6, the program constructs a K4 core with t paths 1–u_i–v_i attached to vertex 1. It independently enumerates hops, generates their groups, checks connectivity and edge counts, verifies the pendant transpositions and partition obstruction, and checks that deleting either core diagonal gives a hop-maximal and leap-maximal graph whose intersection is neither. For t at most 2, hop enumeration is also checked against all permutations. An exhaustive check of the 64 spanning subgraphs of K4 exhibits failure of intersection closure for each entire family.

The tuple order in the output is C_t, H1_t, H2_t, G_t. The first three leap groups have order 8; the ambient group has order 24 at t=0 and 48 at positive tested t. The program checks only the stated finite range. The all-t argument is a mathematical preregistration outline, not a consequence of finite testing or a Lean proof. No matroid enumeration is used: intersection closure is a necessary condition for any matroid's flats.
