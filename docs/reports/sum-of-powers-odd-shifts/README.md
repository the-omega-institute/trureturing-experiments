# Benfield–Lippard odd-shift parity check

`check.py` uses exact Python integer arithmetic to reproduce the published
values of `(a_k,b_k)` for `2 ≤ k ≤ 9`. It also checks the proposed structural
identity on bounded intervals for `k = 2, 3, 4, 5`: if `S` is generated by
`n^k−1` and `T` by `2^k−1` together with `(u^k−1)/2` for odd `u ≥ 3`, then
`S = 2T ∪ ((2^k−1)+2T)` on the checked interval. The output is stored in
`check.out`; the final line is `ALL_CHECKS_OK`.
