# Full-divergence lift at an off-critical weight

Source: V. Borovik, C. de Korte, N. Meurrens and D. Pavlov, *Constraining Conformal Correlators*, arXiv:2605.31491v1, Conjecture 8.7, equations (57)–(64). Supplement: [Zenodo 22208208](https://doi.org/10.5281/zenodo.22208208), CC-BY-4.0. This is an independent Python implementation of the source formulas; the seven explicitly attributed critical-weight coefficients are transcribed from the supplement's `D2Solution.m` (SHA-256 `dd885d778abb066c5d625759b918f33f24258ec10d9eef087b3823c5eb9bd113`).

Run `python3 check.py`. Python 3.14.8 and SymPy 1.14.0 produced `output.txt`, ending in `ALL_CHECKS_OK`. All evidence uses integers, rational numbers or exact symbolic expressions. Script SHA-256: `dc9836709a1bf2939e35e0fa03b98ccd79bb0ea45e980e58add15876b06e8872`.

The fidelity checks reproduce all 17 formal monomial counts in Table 3, compare Proposition 3.9 / equation (24) with direct enumeration for all 343 spin triples in [0,6]^3, and reproduce the authors' critical-weight second-order operator on the complete five-dimensional formal space W_(2,1,1) at Delta=(2,2,2). The supplementary operator has 461 coefficient rules; only seven nonzero rules can act on these five inputs. No numerical rank computation is used.

For every integer r >= 2, set d=3, s=(2,1,1), t_1=0 and Delta=(2r,r+1,r+1). With K=P12^(-r-1) P23^(-1) P13^(-r-1), the five normalized twice-diverged images are (aT+J,-aT-J,-aT-J,bT+kJ,eJ), where T=V2 V3, J=H23, a=(2r-1)(r+1), b=-2(r+1)^2, k=2(r^2-3r+1), e=r(2r-3). The displayed polynomial operator in `check.py` realizes all five images. Its order is four, within the source construction's bound of six, and it contains no derivative with respect to H23. This tests failure of the necessity direction: an operator exists although Delta_1 != d-1+t_1.

The symbolic computation differentiates the contractions with the four fixed vectors P2,P3,Z2,Z3 using their Gram matrix. Differentiation of particle 1 occurs before imposing any particle-1 cone constraint. A separate coordinate implementation differentiates rational functions in five ambient P1 coordinates and five ambient Z1 coordinates. It checks every basis element at r=2 and r=3 on the stated nonzero real-position / complex-polarization cone witness. The outputs at r=2 are (320,-320,-320,-640,-512), with K=-64. The outputs at r=3 are (4096,-4096,-4096,-10240,-9216), with K=-256.

Boundary: these are exact algebra checks, not a Lean proof. The five listed monomials span the entire formal source space, so this is not a test of only one selected correlator. The independently computed coordinate evaluations are extra checks; the infinite family is checked by symbolic identities. Intrinsic conformal-primary shortening and independence of ambient representatives are separate questions.

A first-order normalization discrepancy is not used as evidence: at d=3, s=(1,0,0), Delta=(2,3,5), literal coordinate differentiation using (57) gives K^(-1) C_1(K V1)=-1, while the supplement's `D1Solution.m` coefficient a[1] is +1. Its cause is unverified. The squared target and critical-weight D2 fidelity are computed directly from (57); neither assumes the first-order coefficient agrees.
