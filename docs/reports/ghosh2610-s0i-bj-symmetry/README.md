# Ghosh S0I and Birkhoff–James symmetry

Source: Souvik Ghosh, *On the simultaneous zero inclusion property and characterization of Inner product space*, arXiv:2610.13378v1, Example 4.6 and the concluding conjecture.

Run `python3 check.py`. The program uses only the Python standard library, integers and `fractions.Fraction`. Its output is in `check.out`; success ends with `ALL_CHECKS_OK`.

The fidelity check verifies Example 4.6's Euclidean matrix, its inverse, the zero numerical-range witnesses, its norm-attainment set and an exact positive-semidefinite certificate for the operator-norm inequality showing that T is not Birkhoff–James orthogonal to I. The identity checks multiply coefficients in the algebra generated by an idempotent P with P²=P, using Gaussian rational scalars. They verify the two explicit inverse formulas and the reflection equation on every shift in the stated finite rational grid.

For p=3,…,8 the program takes u=(1,2), y=(2^(p−1),−1) and the rank-one projection P=u j(u)/(1+2^p), where j(u)=(1,2^(p−1)). Hölder's inequality gives ||P||=1 and u perpendicular_B y. An exact rational displacement verifies failure of reverse orthogonality. At v=(2,−1), the normalized spatial numerical value is z=−(2^(p−1)−2)²/(1+2^p)²<0. With T=P−zI, the program verifies both inverse identities and the supporting zero. For every unit norming pair (w,g), Re g(Pw)≤1, so Re g(T⁻¹w)≥1/(1−z)>0. This excludes zero from W(T⁻¹) over both real and complex scalars. The program also checks this lower bound at all nonzero vectors in {−3,…,3}².

The p=4 matrix is T=(1/289)[[53,136],[34,308]], with z=−36/289 and the inverse lower bound 289/325. These exact examples support the contrapositive mechanism; they do not prove the universal conjecture. The norm-one assertion and uniform inverse bound use the analytic argument just stated; the finite computation verifies their algebra and explicit witnesses, rather than certifying all norming pairs by enumeration. No floating-point evidence or Lean proof is included.
