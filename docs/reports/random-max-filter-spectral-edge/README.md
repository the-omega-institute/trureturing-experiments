# Random max-filter spectral edge

Independent checks of Efstratios Tsoukanis, *Distortion of Random Max Filters over Reflection Groups*, arXiv:2611.00305v1, Remarks 2.7(iii), https://arxiv.org/abs/2611.00305v1.

Run `python3 check.py` with SymPy installed. It uses integer, rational and symbolic arithmetic only. It reproduces the uniform-order-statistic covariance inverse stated after Lemma 3.1, checks exact simplex spacing moments, and tests every admissible location and even packet length for sample sizes 3 through 24 (1,078 packets). It checks the two iterated algebraic limits and the normal/half-normal constants symbolically. The stored output ends with `ALL_CHECKS_OK`. These checks do not prove Gaussian local L2 convergence or the conjectured spectral limits.

Run `OPENBLAS_NUM_THREADS=1 python3 quadrature.py` with NumPy and SciPy installed to reproduce the numerical screening. For i < j, U_(j) has Beta(j,n+1-j) law and U_(i)/U_(j), conditional on U_(j), has Beta(i,j-i) law. Gauss-Jacobi rules therefore integrate Q(v)Q(vt) against those two beta densities; diagonal entries use Q(v)^2. Use Q = Phi inverse for S_n and Q(u) = Phi inverse((1+u)/2) for B_n. The program doubles 220 nodes until the scaled smallest eigenvalue changes by less than 1e-5, with a limit of 3,520 nodes. It also checks the source lower bound within quadrature tolerance and relative trace error below 4e-5. This is a numerical convergence diagnostic, without certified interval error bounds.

At n=96, the computed n^2 lambda_min values are 1.568134360991 for S_n and 0.389455978555 for B_n, compared with pi/2 = 1.570796326795 and pi/8 = 0.392699081699. At n=64 the S_n result is 1.566958223350, agreeing with the source's rounded value 1.5670. The full table and successive-node differences are in `quadrature-output.txt` and `quadrature-results.json`. Finite-size values need not be monotone: S_4 is closer to pi/2 than S_8. Monotonicity is not part of the source assertion.

The matrices are population second moments of sorted iid Gaussian or absolute Gaussian coordinates. They already correspond to the limit of infinitely many templates at each fixed dimension. No joint limit in dimension and template count is tested or asserted. The code was written independently from the probability formulas in the paper; no author program or third-party settlement code was copied.
