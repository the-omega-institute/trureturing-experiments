# Che–Qi–Wei Conjecture 1 in arXiv:1501.02546v1

Run `python3 check.py` with Python 3.12 or later and SymPy. The recorded output uses Python 3.14.8 and SymPy 1.14.0. The script enumerates ordered tensor indices and uses exact rational and symbolic algebra throughout.

The fidelity check specializes Theorem 5(a) to a positive-definite diagonalizable binary quartic and determines the solution on each support. The remaining checks verify the quartic and Jacobian identities, test the dense coupling in dimensions 2, 4, and 6, check that symmetrizing Bai–Huang–Wang’s Example 3.2 retains both solutions, and evaluate the two rational solutions for the same right-hand side. The family checks represent each positive radial scale by its cube and verify equality of the resulting slacks by homogeneity.

The targeted conjecture is the broad symmetric statement in the January 2015 arXiv version. The later author-hosted manuscript restricts its conjecture to diagonalizable tensors.
