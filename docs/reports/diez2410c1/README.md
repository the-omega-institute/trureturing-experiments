# Diez, Weak free Cramér's conjecture

Run `python3 check.py` with SymPy installed. The script uses exact arithmetic. It reproduces the semicircle moment formula in Definition 2 of arXiv:2410.02470v2. It checks the boundary and curvature algebra for the polynomial inverse Cauchy transform on the parameter range 0 < e ≤ 1/16, the endpoint matching conditions, and the moment and R-transform identities for the two factors.

The analytic argument supplies the measure, its global logarithmic equilibrium certificate, and the free convolution identification. The script checks the algebra used by that argument.
