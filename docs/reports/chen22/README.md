# Chen–Mortici gamma remainder

Run `python3 check.py` from this directory. It uses only the Python standard library. The expected output is in `check.out`.

The check reconstructs the Bernoulli numbers from (11) of Chen and Mortici, *Asymptotic expansions and inequalities relating to the gamma function*, and recovers (49) and (50). It checks the exact coefficient sum for the counterexample at order 19 and the rational base and growth bounds used for the infinite counterexample family. The analytic identities and limits that use these bounds are mathematical inputs to the check. [Journal article](https://doi.org/10.2298/AADM200710034C)
