# Predictive-complexity upper-bound check

This exact-arithmetic check concerns the unnumbered conjecture following Equation
(19) in Curtis T. Asplund and Elisa Panciu, *Predictive Complexity of Quantum
Subsystems*, Entropy 26(12), 1065, DOI 10.3390/e26121065; arXiv:2309.15200v4,
Sections 2.1–2.4. Equations (18), (23), and (26) specify the nonlinear merge used
here. The program implements that prescription directly.

Run `python3 check.py > output.txt` with Python 3 and SymPy. The program first
reproduces the source's Bell-state example: the original spectrum is (1/2,1/2),
and the merged spectrum is (1,0). It then checks the exact channel generated by
H = Z ⊗ |3⟩⟨3| and the vanishing cross partial trace on span{|1⟩,|2⟩}.

For u,v,t > 0, u ≠ v, t² > (u+v)²/2, the input rows are (u,v,t) and (v,u,−t),
divided by √(2(u²+v²+t²)). The checked determinant difference is
(u−v)²(2t²−(u+v)²)/(4(u²+v²+t²)²) > 0. Both qubit marginals have equal diagonal
entries, so the more balanced merged spectrum has larger natural-log entropy.
At (u,v,t)=(3,1,3), an integer-power comparison independently establishes the
strict entropy increase, with spectra (8/19,11/19) and (9/19,10/19).

All calculations use symbolic algebra, integers, or exact fractions. There is no
floating point evidence. The binary-entropy comparison uses the displayed
derivative and monotonicity of the real logarithm. This is a preregistration
check, not a Lean proof or a certification of complete literature coverage.
