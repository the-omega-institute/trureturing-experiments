# Wilson's diagonal almost-prime ratio conjectures

Run with Python 3 and internet access:

```sh
python3 docs/reports/a078841-almost-prime-diagonal-ratio/check.py
```

The program uses only integers and `fractions.Fraction` for mathematical checks.
It downloads the two official OEIS b-files, verifies their SHA-256 fingerprints,
and reproduces all 1001 terms of A078841 and all 1000 terms of A101695 by
exhaustive rational enumeration of the monoid generated by odd primes divided
by two, through 4437/16. This bound gives exactly 1001 monoid elements, using
odd primes through 547. It checks A101695(n+1) = 2 A078841(n) for n = 0..999.
An independent integer prime-power sieve through 1105920 verifies the defining
order ranks for A078841 at n = 0..16 and A101695 at n = 1..17.

`output.txt` is the program's output; its final line is `ALL_CHECKS_OK`.
These are finite source-fidelity and proposed-rank-identity checks. They certify
neither ratio limit and contain no Lean proof. The planned settlement uses a
general rank argument and an eventual semigroup-gap argument.
