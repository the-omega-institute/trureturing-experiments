# Stallings proximacy: exact finite checks

Source: L. Asencio-Martín, J. R. Britnell, A. Duncan, D. Francoeur and S. Rees,
*Stallings foldings for rational subsets of automatic groups*,
[arXiv:2607.26284v1](https://arxiv.org/abs/2607.26284v1), Question 3.10.

Run with Python 3.12 or newer:

```sh
python3 docs/reports/abdfr-2607-stallings-proximacy/check.py
```

The standard-library program uses integers only. Its saved output is
`check-output.txt`; success requires exit 0 and final line `ALL_CHECKS_OK`.

For d ≥ 2 the group coordinates are (v,h) in Z^d × Z, with
(v,h)(w,k) = (v + σ^h(w), h+k), where σ(e_i) = e_(i+1 mod d).
The signed generating set contains every coordinate step and t=(0,1).
The normal-form block order is a_1, a_0, a_2, ..., a_(d−1), t, with each block
using one sign. The positive submonoid is generated by a_0 and t.

The fidelity check reproduces the coordinate obstruction of source Remark 3.3
in Z^2. The family check compares w_N=a_1^N a_0^N t with
u_N=a_0^N t a_0^N: they have the same endpoint and length 2N+1, while the
prefix a_1^N has minimum distance N from the second path. It checks 900
instances (2 ≤ d ≤ 10, 1 ≤ N ≤ 100). Every positive word through length 11
is checked to be geodesic, and the witness endpoints through N=5 have unique
positive representatives within that exhaustive enumeration.

For d=2,3 the program also checks signed edges against the full coordinate
grid; independently computes the radius-4 Cayley ball by BFS; constructs
shortest paths between every pair in the coordinate box [-1,1]^(d+1);
checks the submonoid description on v in [-2,2]^d and h in [-2,5]; and checks
8,050 right-adjacent normal-form pairs based at v in [-2,2]^d, h in [-3,3].
Their maximum synchronous fellow-traveller distance is 2.

Two explicit finite-state transition rules recognize the block language L
and its positive-submonoid representative language J. Their acceptance is
compared with separate block-order and coordinate predicates on all signed
words through length 5 (9,331 words for d=2; 37,449 for d=3), and on every
canonical form in the stated normal-form box. J stores the greatest spatial
index seen and the t count capped at d−1, rejecting negative letters.

These are finite consistency checks, not proofs of universal automaticity,
regularity or the absence of a uniform proximity constant. Those assertions
need the mathematical argument and later Lean verification. The source's
printed comparison-index bound is |w′| although its map has domain [0,|w|];
the witness lengths coincide, so this discrepancy does not change the check.
