# Singular four-Gaussian sign residual

`check.py` uses SymPy exact integers, rationals, radicals, and symbolic inverse
trigonometric values.  It checks the four-sign identity on all 14 nonconstant
sign patterns, reproduces the source's Theorem 7.1 value
`Omega(pi/2) = 2/(3*pi)`, and compares the correlation formula with direct
spherical-area calculations for rank-one, rank-two, and rank-three direction
systems.  No floating-point value is used as evidence.
