# Kushkuley Conjecture 5.1

Run python3 check.py with Python 3.12 or later. The program uses only the
standard library and exact integer and rational arithmetic. Its output is
stored in [output.txt](output.txt).

The fidelity check reconstructs the five-dimensional character of A₅ from
its action on the six Sylow 5-subgroups. It reproduces the level-set sizes
and probabilities of Example 5.1 and checks Lemmas 5.3 and 5.5(i) at
exponent one. The counterexample check enumerates all ordered pairs
of S₄ and factors their counts and moments to check all targets in S₄,
S₄² and S₄³. It checks the parity-coset witnesses and the uniform
positive lower bound on the gap for these three instances.

Source [arXiv:2603.23614v2](https://arxiv.org/html/2603.23614v2).
