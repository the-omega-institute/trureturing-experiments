# Dewar et al. Conjecture 6.6

Run `python3 check.py` with Python 3.12 or later. The script uses only the Python standard library. Its expected output appears in `check.out`.

The fidelity check counts labelled squared-distance tuples for the complete triangle on equally spaced collinear points, the tightness example for Corollary 1.8. The settlement checks enumerate triangle trees and all vertex assignments for three small square-grid cases, compare the image with the bridge product bound, and verify the arithmetic restriction for primes 3, 7 and 11. The asymptotic claim uses the mathematical argument in the preregistration. [Source, arXiv:2505.06590v1](https://arxiv.org/html/2505.06590v1)
