# Supported-product extension checks

Source: Ziemowit Kostana, *Pure-homogeneous Abelian groups*, arXiv:2607.11525v1, Theorem 3.1, Lemma 1.2 and Question 3.5. https://arxiv.org/abs/2607.11525v1

Run with Python 3:

```sh
python3 docs/reports/kostana-pure-homogeneous-supported-product/check.py
```

The program uses integers and finite sets only. A group is represented as a product of finite cyclic groups; every subgroup and every relevant homomorphism is enumerated. The homomorphism enumerator checks generator-order relations and independently verifies every addition-table identity.

The fidelity checks reproduce the maximal co-cyclic quotient diagonal pure embedding from Theorem 3.1 and the finite case of Lemma 1.2 (a pure subgroup is a direct summand). They cover all abelian groups of order at most 8, both order-9 groups and all five order-16 groups.

The extension checks cover every pure subgroup A of each listed B, every abelian D of order at most 4 and every pure embedding A into D. They construct the actual quotient pushout (D plus B) modulo the graph of A, check injectivity and purity of both inclusions, find and verify a retraction onto D, identify the fresh component with B/A, and check the resulting pure embedding of B into D plus B/A. The output records 558 diagrams and 9930 quotient elements. A nonpure subgroup C2 of C4 gives a negative control: its identification with C2 cannot extend to a homomorphism from C4 to C2.

These finite checks support fidelity and the algebraic extension mechanism. They do not establish infinite algebraic compactness, cardinal regularity, the size or extension property of the infinite supported product, or the transfinite back-and-forth argument. The proposed positive settlement requires a general proof; this finite computation is not the settlement.

The script is original checking code, uses only the Python standard library, and incorporates no source-paper code or datasets. The stored output is generated by the script.
