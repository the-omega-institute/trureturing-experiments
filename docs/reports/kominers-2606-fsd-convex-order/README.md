# Formal self-duality and half-weight convex order

`check.py` checks the open formally self-dual extension in Scott Duke Kominers,
*Majorization and Gaussian-Mass Maximality for Construction-A Lattices from
Binary Self-Dual Codes*, arXiv:2606.03482v2, Section 5.

Run with Python 3.12 or newer:

```sh
python3 docs/reports/kominers-2606-fsd-convex-order/check.py
```

The program uses only the standard library, integers and `fractions.Fraction`.
`output.txt` contains its output; success ends with `ALL_CHECKS_OK`.

- **Source fidelity:** constructs the extended Hamming code as RM(1,3), enumerates
  its dual independently, and reproduces the paper's weight enumerator
  `1 + 14*z^4 + z^8` and gap `4*z^2*(1-z^2)^2`.
- **Counterexample:** enumerates the sixteen words generated by `11110000`,
  `00001100`, `00001010`, `00001001`, and checks the independently computed dual.
  The code is full-support, even and formally self-dual. Its half-weight law is
  `(1,6,2,6,1)/16`; the centered-square expectations are `5/4` and `1` for the code
  and Bin(4,1/2), respectively. The enumerator excess is
  `2*z^2*(1-z^2)^2`, with value `9/32` at `z=1/2`.
- **Family:** for `C_m = Rep_m ⊕ Even_m`, checks the coefficient distributions,
  exact parity-fiber counts and moment formulas for `3 <= m <= 64`. The variance
  excess is `m*(m-3)/16`; the code is even when `m` is even. Independent ambient
  dual enumeration for `3 <= m <= 8` verifies block-swap isoduality, full support
  and minimum distance two. The all-parameter argument uses the two dual blocks
  and pairwise independence of parity-block bits for `m >= 3`; a finite run is
  not a proof for unbounded `m`.
- **Minimum distance boundary:** exhausts all systematic `[2k,k]` presentations
  `[I|A]` for `1 <= k <= 4`, testing equality with the dual weight distribution
  and the exact hinge criterion. Among the presentations with minimum distance
  at least three, none violates domination: their counts for `k=1,2,3,4` are
  `0,0,24,4416`. These are presentation counts, not equivalence classes. Every
  binary linear code has a systematic presentation after a coordinate
  permutation, so this covers these lengths. Larger lengths remain unsettled.
- **Doubly even boundary:** the 24 doubly-even formally self-dual presentations
  at `k=4` are self-dual. In general, polarization of weights shows that a
  doubly-even binary linear subspace is self-orthogonal; formal self-duality
  forces half dimension, hence self-duality. The source's theorem then applies.

The hinge check uses every half-integer knot in the common finite support and
an exact equal-mean check. Linearity between consecutive knots gives all hinge
inequalities; interpolation gives all convex test inequalities on that support.

These checks support a preregistration. No Lean proof of the claim or its
negation is included. The code is independently written from the mathematical
constructions; no third-party program source is used.
