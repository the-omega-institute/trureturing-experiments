# Expanded-generator delta sets

Exact-arithmetic checks for Ashwin Narayan, *The Delta Set of a Numerical Monoid
Generated by a Generalized Arithmetic Sequence*, arXiv:2610.02495v1,
Conjecture 18.3. The source uses coordinate factorizations relative to the
displayed tuple, so the redundant generator `ah` is retained.

Run with Python 3.8 or later:

```sh
python3 docs/reports/numerical-monoid-delta-set/check.py
```

`out.txt` is the program's output, ending in `ALL_CHECKS_OK`. The program uses
only Python integers and the standard library.

The fidelity checks reproduce the source's explicit Section 3 Euclidean and
arithmetic-component calculation for `(a,h,d,k)=(4,143,109,2)`, and independently
enumerate factorization lengths through `n=2000` for the Theorem 12.1
specialization with generators `(3,8,10)`. The first check reproduces the stated
formula calculation; the second is a finite-window comparison with that formula.
Neither is an independent proof of the source's global theorem.

For the proposed counterexample family, `a` is odd and at least 3,
`h=d=2`, `k=a-1`, and the displayed tuple is `(a,2a,2a+2,...,4a-2)`.
The program checks all three proposed rewrite identities for odd `a=3..101`,
normalizes every coordinate factorization with `n<=120` for
`a` in `{3,5,7,9,11}`, and compares those enumerated lengths with an independent
integer-bitset dynamic program. For every odd `a=3..31` it checks that each
nonempty length set through `n=5000` is an integer interval. The observed delta
set in each window is `{1}`, while the conjecture predicts `E(1,2)={1,2}`.

These checks support the proposed refutation route. Finite windows alone cannot
exclude a delta value at larger `n`; that remains an obligation of the uniform
normalization argument and its eventual formal proof. No Lean proof accompanies
this experiment.
