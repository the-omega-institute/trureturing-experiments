# PRS conditional intertwining check

`check.py` is an exact-arithmetic finite reproduction for Adrian Padellaro, Sanjaye Ramgoolam, and Ryo Suzuki, arXiv:2610.10745v1, Section 4.3, Conjecture 2. It constructs the finite permutation centraliser algebra, the Young-height cutoff as the kernel orthogonal complement, the derangement orbit span, their intersection, the coefficientwise orthogonal projection, the permutation operator at ξ = 1/N, and the actual traceless contraction.

The check first reproduces the published traceful identity qH = Δq at (m,n,N) = (2,2,2). It then checks fP = f on all ambient basis vectors and the traceless identity F(PHu) = Δ′F(u) on every basis vector of U for the twelve cases printed in the output, including empty degree, N=1, and zero bidegrees. Exact rank checks verify that F is injective on U and spans the whole contraction image. Solving in the U and F(U) bases checks the inverse form of the intertwining identity as well. The source invariant-theory theorem identifies the contraction image with the physical invariant space; the program does not independently prove that theorem.

Both sides contribute to the monomial coordinate set, so no output term is discarded. The coefficientwise basis uses distinct orbit sums; the source uses subgroup sums, which differ by the explicit nonzero stabilizer factor. The cutoff is computed using the published equivalence in the source with the kernel orthogonal complement; the program does not independently construct Young-labelled SEP bases. All coefficients use integers or exact `sympy.Rational` values; the script uses no floating point arithmetic. The output is stored in `check.out` and ends with `ALL_CHECKS_OK`.
