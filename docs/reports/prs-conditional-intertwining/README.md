# PRS conditional intertwining check

`check.py` is an exact-arithmetic finite reproduction for Adrian Padellaro, Sanjaye Ramgoolam, and Ryo Suzuki, arXiv:2610.10745v1, Section 4.3, Conjecture 2. It constructs the finite permutation centraliser algebra, the Young-height cutoff as the kernel orthogonal complement, the derangement orbit span, their intersection, the coefficientwise orthogonal projection, the permutation operator at ξ = 1/N, and the actual traceless contraction.

The check first reproduces the published traceful identity qH = Δq at (m,n,N) = (2,2,2). It then checks fP = f on all ambient basis vectors and the traceless identity F(PHu) = Δ′F(u) on every basis vector of U for the twelve cases printed in the output, including empty degree, N=1, and zero bidegrees. Both sides contribute to the monomial coordinate set, so no output term is discarded. The coefficientwise basis uses distinct orbit sums; the source uses subgroup sums, which differ by the explicit nonzero stabilizer factor. All coefficients use integers or exact `sympy.Rational` values; the script uses no floating point arithmetic. The output is stored in `check.out` and ends with `ALL_CHECKS_OK`.
