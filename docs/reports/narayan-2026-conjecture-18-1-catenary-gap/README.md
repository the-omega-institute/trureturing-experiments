# Narayan's catenary-gap conjecture: exact finite checks

Source: Ashwin Narayan, *The Delta Set of a Numerical Monoid Generated by a
Generalized Arithmetic Sequence*, arXiv:2610.02495v1, Conjecture 18.1.
The tuple is `(a, ah+d, ..., ah+kd)`; it has no separate `ah` coordinate.

Run with Python 3, using only the standard library:

```sh
python3 docs/reports/narayan-2026-conjecture-18-1-catenary-gap/check.py
```

`output.txt` is the output of the exact checked program. All evidence uses
integers. The fidelity checks reproduce the arithmetic tail and subtractive
Euclidean union in Section 4's `(4,681,790)` example, and verify Theorem 17.1
at `(a,h,d,k)=(5,2,1,3)` by computing `c(23)=3`. For the Section 4 example,
only seven of its fifteen predicted delta values occur through `n=12000`;
the program checks containment and does not equate this finite observed
union with the full delta set.

The conjecture window comprises 712 tuples: `5<=a<=12`, `2<=h<=5`,
`1<=d<=8`, `gcd(a,d)=1`, and `3<=k<=a-2`. For each tuple it enumerates every
coordinate factorization of every value from zero through
`max(2*a*h+(k+1)*d,2*a*h+3*d)+a*h`. There are 50,888 represented values,
107,263 factorizations, and 127,296 unordered distance pairs. A minimum
spanning tree of each complete distance graph determines its exact
catenary degree. A separate breadth-first search checks connectivity at
that degree and disconnection one unit below every positive degree.

Every observed degree at most `h+1` belongs to `{0,2,h+1}`, and both positive
values have exact witnesses in each tuple (1,424 witness checks). The
program also checks that each minimum-positive-index-count block has a
single index sum and zero-coordinate count, is connected at threshold two,
and has no crossing edge below `h+1` (53,175 crossing pairs).

These are finite checks. They neither prove the universal conjecture nor
certify the accompanying proposed argument in Lean. The planned positive
settlement uses an argument over all parameters and all represented values;
its computational utility classification is `none`.
