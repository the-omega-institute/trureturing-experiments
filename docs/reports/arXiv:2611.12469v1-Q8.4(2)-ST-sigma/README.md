# Teheux Question 8.4(2): exact finite checks

Source: Bruno Teheux, *Dualities and completions of median algebras and semilattices: a universal-algebraic approach*, arXiv:2611.12469v1, Remark 7.5 and Question 8.4(2), https://arxiv.org/abs/2611.12469v1.

Run with Python 3.12 or newer, without third-party dependencies:

```sh
python3 check.py > check.out
```

The program uses only exact integer masks, sets and comparisons. It reproduces Remark 7.5: the six-vertex tree with two leaves attached to each end of an edge satisfies sigma, whereas its four-leaf-star quotient does not. For both trees it independently compares the geodesic definition of median with majority of the principal ultrafilters and verifies that all ultrafilters are principal.

For parameters p1,...,p4, let C be the union of the four principal upsets generated by their complements and the six intersections of pairs of their principal upsets. The proposed first-order sentence says that every tuple either has a zero parameter or C contains some x and its complement.

The exhaustive check covers all nontrivial bounded poc sets with at most ten elements, up to complement-preserving relabelling. Every such set has even cardinality: a fixed point of complementation would satisfy x <= x* and hence x=0, contradicting 0*=1 and 0!=1. Relabel the bounds 0 and 1 and the other complementary pairs consecutively. Between two proper complementary pairs there are four possible dual orbits of comparisons. Any two distinct orbits force either a nonzero element below its complement or a cycle between distinct elements, so at most one orbit can occur. The program enumerates the five choices for each pair of pairs and retains exactly the transitive relations; it separately validates all poc axioms. Isomorphic relabellings are not deduplicated.

Sigma is checked directly on all distinct centres and unordered sets of four other ultrafilters, using all four median equalities. The first-order sentence is checked independently from the element relation; the nondecreasing parameter tuples include repetitions and represent every ordered tuple because the formula is permutation invariant. For cardinalities at most eight, a separate loop over all ordered nonzero tuples verifies this reduction. Zero parameters satisfy the literal zero disjunction without further conditions.

For each retained structure the program additionally checks majority closure, extension of every nonempty consistent upset, the proposed four-leaf construction for every consistent parameter tuple and every extending centre, and extraction of witnesses from every directly found star. These assertions exercise both directions independently of the direct sentence comparison.

The output reports 2,229 structures, of which 1,420 satisfy sigma and 809 violate it; 54,769 consistent upsets; 1,024 four-leaf constructions and 1,024 extracted stars. Each comparison succeeds, and the final line is `ALL_CHECKS_OK`.

This is finite evidence for the proposed correspondence, not a proof for arbitrary or infinite bounded poc sets. The planned settlement uses a general ultrafilter-extension argument and explicit orientation changes. No Lean proof is included here.
