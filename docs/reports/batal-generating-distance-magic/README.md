# Generating group distance magic: a 16-vertex obstruction

The standard-library Python program checks a proposed finite refutation of
Ahmet Batal, *Algebraic characterizations of generating and affinely generating
Γ-magic maps and Γ-distance magic labelings on regular graphs*,
[arXiv:2609.05934v1](https://arxiv.org/abs/2609.05934v1), Conjecture 4.4.

Run from the repository root:

```sh
python3 docs/reports/batal-generating-distance-magic/check.py
```

The stored stdout is `output.txt`. Every computation uses integers or exact
arithmetic in a finite prime field; the program has no third-party dependencies.
A failed condition raises an exception. Success ends with `ALL_CHECKS_OK`.

The fidelity check reproduces the source's Theorem 4.3: its explicit 27-vertex
simple connected 6-regular graph has identity-label neighborhood sum 84,
reduced adjacency rank 24 over F₃, nullity 2, and the stated 24-by-24 minor
determinant −11. The neighborhood data are transcribed from that theorem.

The candidate has 16 vertices, 48 edges, degree 6, and identity-label
neighborhood sum 51. Its full neighborhood table and spanning tree are in
`check.py`. Thirteen explicit sums of the binary neighborhood-difference rows
have the listed supports. Their equations force every magic map into an
exponent-two abelian group to have labels

```text
(a+b+c, a, a+b+c, a, a+b+c, a, a+b+c, c,
 b,     a, b,     c, b,     c, b,     c).
```

Substitution gives common sum a+b. Thus every label lies in the subgroup
generated by a,b,c, which has at most eight elements. This excludes generating
maps into Γ=(Z/2Z)⁴, whose order is sixteen.

Independent enumeration tests all 65,536 binary scalar maps; exactly eight
are magic, and they equal the formula's eight scalar specializations. All
4,096 choices of a,b,c in Γ satisfy the displayed formula and magic equations;
the generated subgroup sizes have histogram {1:1, 2:105, 4:1470, 8:2520}.
The difference-row matrix has rank 13 over F₂. The certificates establish
completeness of the formula; the vector enumeration does not enumerate all
16¹⁶ unrestricted maps.

These are executable exact checks and a mathematical refutation outline.
They are not a Lean proof or a literature novelty certification. No claim of
minimal counterexample order or of an infinite counterexample family is made.
