# Disjoint-copy contextuality robustness

Exact-arithmetic checks for Axel Muller and Metod Saniga, *Automated search for
highly contextual Kochen-Specker proofs*, arXiv:2609.19862v1, Sections 4.2 and 6.

Run with Python 3, using only its standard library:

```sh
python3 check.py > output.txt
```

The program builds unsigned Pauli words and their exact multiplication phases,
then discovers every independent nonempty set satisfying the neighborhood-parity
condition. It enumerates all base valuations for the pentagram, square and doily.
A direct integer Walsh-Hadamard transform independently checks each base score
and every valuation of two pentagrams and two squares. Explicit Pauli tensor
products verify the signs of their composite contexts. All 64 pairs of graphs on
three vertices check the complete-support decomposition, and all 11,664 pairs of
signed systems and valuations on two vertices check the augmented-score identity,
including negative local factors. Attainable score-value products are checked for
one through eight copies of each base.

The source-fidelity checks reproduce three pentagrams (215 contexts, degree 76),
three squares (342 contexts, degree 109), and two doilies (255 contexts, degree 78).
The corresponding exact errors are 152/215, 109/171 and 52/85. These integer fields
also occur in `3_Petersen.txt`, `3_L_K_3,3.txt` and `2_L_K_6.txt` in the authors'
[data deposit](https://zenodo.org/records/22790412), read together with its README.
The deposit metadata declares CC BY 4.0; no deposit file is redistributed here.

The data in `output.txt` are generated by this program. Every reported value uses
integers or `fractions.Fraction`. Finite checks support a proposed general proof;
they do not prove convergence or constitute a Lean settlement. The infinite-copy
claim is to be established by a general factorization and geometric bound.
