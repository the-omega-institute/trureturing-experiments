# Torun’s four-copy conversion bound

Run python3 check.py with Python 3.12 or later and SymPy 1.14. A successful run reproduces check.out and ends with ALL_CHECKS_OK.

The script checks Proposition 2’s exact two-copy and three-copy optima via the binary matrices and Walsh eigenvalues in Appendix C. For four copies it exhausts the balanced signs, checks the scalar inequalities of both dual cases symbolically, and verifies the rational certificate at overlap 15/17. The exact trace checks on 128 bijections exercise the certificate. The universal treatment of all permutations uses the two-case argument in the preregistration.

Source: Gökhan Torun, “Probabilistic distillation of superposition”, arXiv:2611.16719v1. https://arxiv.org/abs/2611.16719v1
