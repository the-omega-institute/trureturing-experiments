# Cazenave Conjecture 4 (#112951): exact finite checks

Source: Tristan Cazenave, *Lemmas and Conjectures in Spectral Graph Theory*,
arXiv:2611.03879v1, Section 1 and Section 7.
https://arxiv.org/abs/2611.03879v1

Run with Python 3 and SymPy (the recorded run uses Python 3.14 and SymPy 1.14.0):

```sh
python3 check.py
```

The final line must be `ALL_CHECKS_OK`. `output.txt` is the complete output.
The script uses only integers, exact fractions, symbolic eigenvalues of a 2 by 2
matrix, and rational intervals enclosing square roots. No floating-point
calculation is evidence.

Fidelity checks reproduce the source's equality at K2 (adjacency spectrum 1,-1;
ordinary Laplacian spectrum 2,0; Randic index 1) and its formula R(K_n)=n/2
for orders 2 through 9.

The retained graph6 data contains one representative of each connected simple
graph of orders 2 through 9. It was generated by nauty 2.8.9 `geng -cq n` for
each of these orders, then concatenated in order and compressed with gzip
(mtime zero). Counts by order are 1, 2, 6, 21, 112, 853, 11117, 261080;
total 273192. Completeness up to graph isomorphism uses nauty's enumeration;
the checker independently parses each graph, checks connectedness, validates
these known counts and reports hashes. The inequality is invariant under
vertex relabeling, so representatives suffice for all graphs in this range.

For each graph the checker certifies three sufficient inequalities. Choose a
maximum-degree vertex u, write Delta=deg(u), choose v of maximum degree among
the remaining vertices and write d=deg(v), and set r=sqrt(Delta), c=r+d-1.

1. R >= r: the exact radical sum is grouped by squarefree part. Zero is
   detected algebraically; otherwise integer-square-root rational enclosures
   give a strictly positive lower bound for R-r.
2. lambda_1(A) <= c: the checker verifies A*h <= c*h in exact quadratic
   arithmetic for h_u=r and h_i=1 elsewhere. Similarity by diag(h) produces
   a nonnegative matrix whose row sums are at most c, so all eigenvalue
   moduli are at most c.
3. mu_2(L) >= d-1: the u,v principal block of L-(d-1)I is
   [[Delta-d+1,-epsilon],[-epsilon,1]], where epsilon is 1 for an edge uv
   and 0 otherwise. Nonnegative diagonal entries and determinant certify
   positive semidefiniteness; principal-submatrix interlacing gives the bound.

Combining these certificates gives lambda_1 <= r+d-1 <= R+mu_2 for each
actual graph. Thus the minimum target slack on the whole enumerated set is
exactly zero: every slack is nonnegative, and K2 attains zero. This is an
exact certificate check, not a direct numerical eigenvalue table. Its classical
spectral comparison and interlacing steps are mathematical trust assumptions
of this finite experiment; no Lean proof or universal machine verification
is claimed. A general proof is the planned settlement; this finite prefix
supports the route and is not itself a new positive settlement.
