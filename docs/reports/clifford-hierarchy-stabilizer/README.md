# Clifford-hierarchy onsite stabilizers

Exact checks for Fechisin, Cooney, Raja, Albert, Williamson, Kawagoe and
Musser, *Clifford-hierarchy stabilizer formalism with applications to twisted
quantum doubles*, arXiv:2610.00464v1, Appendix B, Conjecture B.5.

Run with Python 3 and SymPy:

    python3 check.py

`output.txt` contains the output. The program uses integer residues, exact
integer Hermite normal forms and elimination over prime fields. It uses no
floating-point arithmetic.

The fidelity checks reproduce Lemma B.3, Example B.4 and equation B16: the
three-qubit CCZ state has only the identity onsite Clifford stabilizer; the
six-qubit generators have order four, pairwise fail to commute, and have one
common invariant ray on the indicated eight-point affine support.

The settlement checks compare the entire finite phase groups generated by the
canonical nonclassical monomials and by univariate phases of linear forms,
modulo constants. This checks every group element without enumerating each
phase. The groups are represented as full-rank integer lattices containing
Q times the coordinate lattice; equality of Hermite normal forms is exact.
The canonical classification is Tao–Ziegler's, as stated in Hatami–Hatami–Lovett,
arXiv:1403.7703v2, Lemma 2.6. The common denominator is
Q = p^(1 + floor((r-1)/(p-1))). Both lattices include every constant modulo Q.

The 29 parameter cases are p=2, ell=2, 1<=r<=7; p=2, ell=3, 1<=r<=6;
p=3, ell=2, 1<=r<=6; p=3, ell=3, 1<=r<=4; and p=5, ell=2, 1<=r<=6.
Here r=k+1 is the proposed wavefunction phase degree; r=1 additionally checks
the induction base. Each case also checks all coordinate differences of
order r+1 at every base point for both generating families, the rank of the
pure symmetric tensor evaluation matrix over F_p, and the nonzero constant
r-th derivative of the designated one-variable phase.

The finite checks support the proposed all-prime, all-level span argument.
They do not prove Conjecture B.5 or certify a Lean proof. No Lean proof is part
of this report.
