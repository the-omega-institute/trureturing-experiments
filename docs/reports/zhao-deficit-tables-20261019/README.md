# Zhao extended deficit tables (19 October 2026)

This report preserves the numerical data from Chengye Zhao's extension of the Italian-domination cycle tables through deficit `j = 16`, together with the source-path layout used in the verification archive. The files are published here because university mail filtering treated some ordinary decimal table entries as possible payment-card numbers: they are mathematical coefficients, not payment-card or identity data.

The copied files retain their original archive paths beneath this directory. `verification/received/extended-deficit-tables-j0-16.zip` is the original nested received archive; its extracted data files are also present at `verification/received/ext/`.

Source package: `verification_20261019.zip` from the accompanying research exchange. The three extended data files have these SHA-256 values:

- `coefficients_extended.csv`: `b4fb7548637969baeba6e3f0b8c7a68603e7b0e82ed3259e9f5ed014e537216d`
- `deficits_extended.csv`: `66ace88ed01920a992332629e05da1e50790b2becb988534a83fa3b3c2e3fb26`
- `deficit_formulas_extended.json`: `76d57b5ad2bfb089957bbf5c81d738d53133f9021138ec168ff8357b2d9f245f`

The data are credited to Chengye Zhao, with the verification and explanatory note by Haobo Ma and Wenlin Zhang.
