# Designolle–Vértesi–Pokutta: the symmetrised local polytope is not always a cross-polytope

`check.py` supports a refutation of the conjecture in Section V of arXiv:2310.20677v3 (Phys. Rev. A 109, 022205 (2024)): "the symmetric polytope is affinely equivalent to the cross-polytope in dimension ⌈m/2⌉ [...] We conjecture, however, that it holds in general." It fails for N = 3 parties and m = 17 inputs.

Conventions: inputs 0..m−1 with e_m = −e_0. A strategy a ∈ {±1}^m is A(X) = Σ a_x X^x in ℝ[X]/(X^m + 1). For three parties, the symmetrised point of (a, b, c) is P(ABC)/m², with P(D) = (d_0, (d_r − d_{m−r})/2 for 1 ≤ r < m/2).

- (A) The source's Reynolds operator, built literally by closing the group generated by g1–g4 of Eq. (25) on the tensor basis, gives coordinates p̃_{r,0,0} equal to P(ABC)/m². The mirror relation of Eq. (27) holds on the remaining coordinates. Checked on all strategies for m = 4, 5 (|G| = 192, 300) and on 3000 random strategies for m = 6, 7.
- (B) The number of distinct symmetrised points matches the source's Table II for N = 3: 10, 10, 60, 100, 640, 1540, 10032 for m = 3..9.
- (C) For odd m = 5, 7, 9, 11, 13, every symmetrised point satisfies ‖V⁻¹q‖₁ ≤ 1, where V_j = P(S_j³) and S_j = sign cos(πjx/m) for odd j ≤ m. So for these m the polytope is the cross-polytope conv{±V_j}.
- (D) m = 17:
  - V is a 9 × 9 integer matrix with det V = 98400527135576109875200.
  - For each odd j < 17, max |A(ζ^j)| over all 2¹⁷ sign vectors is csc(π/34), attained exactly at the 34 signed rotations of s_j; for j = 17 the maximum is 17, attained twice. So each ±V_j is a uniquely exposed vertex.
  - The strategies (a, b, c) give p = P(ABC) = (−141, 133, −109, 69, −13, −43, 91, −123, 139), and w = (−15, 27, −21, 8, 59, 24, −5, −6, 10) gives w·p = 8421 > 8417 = max |w·V_j|.
  - So the polytope has more than 18 vertices, and the 9-dimensional cross-polytope has 18.

Run: `python3 check.py` with numpy 2.4 and sympy 1.14 (exit 0; final line `bad= 0`; about 17 s).
