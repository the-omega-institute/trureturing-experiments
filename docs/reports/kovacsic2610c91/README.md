# Cubides Kovacsics–Uribe Rincón Conjecture 9.1

Run `python3 check.py` with Python 3.12 or newer and SymPy 1.14.0. The script uses exact rational coefficients throughout. Its output is in [check.out](check.out).

The first check reproduces both denominator and valuation conclusions of Proposition 6.2(1–2) on 19 rational functions in the Laurent variable. For each transcendence degree from 1 through 4, the second check tests the Kochen values, the two excluded elements, and the weighted valuation against the valuation obtained by rescaling the first variable. It also finds rational points avoiding specified finite lists of zeros inside the open box. The sampled box constraints and valuation computations test the ingredients of the counterexample. The universal-theory realization and containment for all generators use the mathematical argument in the preregistration draft. [arXiv:2610.14417v1](https://arxiv.org/abs/2610.14417v1)
