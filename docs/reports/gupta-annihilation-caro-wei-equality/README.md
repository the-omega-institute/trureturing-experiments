# Annihilation–Caro–Wei equality checks

Source: Chakshu Gupta, *An annihilation-number Caro-Wei bound: a TxGraffiti conjecture and an independence-number bracket*, arXiv:2606.29553v1, Corollary 1 and the unnumbered structural equality question in Section 3.

Run with Python 3 (standard library only):

```sh
python3 docs/reports/gupta-annihilation-caro-wei-equality/check.py
```

The program uses integers and `fractions.Fraction`. It reproduces the source's K4 invariant values and the excluded K2 failure. It checks both the source's inequalities and the proposed complete isomorphism classification on all 27,474 labelled connected simple graphs of orders 3 through 6. Graphs are generated by every subset of the possible unordered edges, then filtered for connectedness. Independence numbers use all vertex subsets. Membership in the proposed list uses explicit adjacency-preserving bijections, with vertex degrees used only to prune that search.

Annihilation numbers are independently compared between sorted-prefix and all-subset implementations. Residues are independently compared between sorted-list and degree-multiplicity implementations of Havel–Hakimi. The long path and cycle checks use a two-state integer dynamic program for independence numbers and direct degree sums and Havel–Hakimi for the other invariants.

Every proposed equality graph is checked explicitly. Among paths with 3 through 300 vertices equality occurs exactly at orders 3, 4, 6; among cycles it occurs exactly at orders 3, 4, 5, 7. The output is in `output.txt`; its final line is `ALL_CHECKS_OK`.

These are finite checks, with no claim to an exhaustive census above six vertices. They support a preregistration whose planned proof is a general degree-reduction, classical Caro–Wei rigidity, and Havel–Hakimi recurrence argument. Neither a proof of the universal classification nor Lean settlement is included.
