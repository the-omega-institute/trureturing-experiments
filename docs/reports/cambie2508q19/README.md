# Cambie–Jooken–Wagner Question 1.9

Run `python3 check.py` with Python 3.12 or later. The script uses only the standard library. The expected output is in `check.out`.

The check reproduces the path equality in Theorem 1.2 of arXiv:2508.20593v2 for orders 1 through 8. It independently enumerates connected vertex subsets and tree subgraphs of the 15-vertex family member. It compares direct cycle-interval counts with the marked-gap formula for four members and verifies the four moment polynomials by their degree bounds and six exact evaluations. The coefficients of the shifted cross-product, the rational gap at 500 and the asymptotic coefficient use exact arithmetic. The graph-to-polynomial bijection is a mathematical step in the preregistration outline.
