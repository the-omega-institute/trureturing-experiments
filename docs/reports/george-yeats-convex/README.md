# George–Yeats convex-subset specialization

Run `python3 docs/reports/george-yeats-convex/check.py` from the repository root.
The program uses only Python's standard library and integer arithmetic;
`output.txt` contains its complete output. Its final line is `ALL_CHECKS_OK`.

Source: Ian George and Rowan Yeats, *A Generating Polynomial for Convex Subsets
of Posets*, arXiv:2610.23399v1, Definition 2.1, Examples 2.2–2.3, the antichain
example in Section 2.5, and the specialization question after Corollary 3.6.
The source polynomial uses the downset generated by the maximal elements and
the upset generated by the minimal elements of each convex subset, including
the empty subset. The checked specialization is Φ(P;1,t,x,y,z).

Fidelity checks reproduce the singleton and the complete five-variable diamond
formula, and the antichain identity for sizes 1 through 8. The source's diamond
has 13 convex subsets.

The program generates all SP construction trees through 8 elements, normalizes
associative disjoint unions and ordinal sums, and checks the resulting classes
using a decomposition computed independently from their order relations.
An independent census enumerates every naturally labelled poset through
6 elements, checks the induced-N-free characterization, and obtains exactly
the same SP class sets. Every finite poset has a natural labelling along a
linear extension, so this census covers all isomorphism classes in its range.

Across 3,096 nonempty SP classes through 8 elements, no two classes have the
same four-variable polynomial. The class counts for sizes 1 through 8 are
1, 2, 5, 15, 48, 167, 602, 2,256. Additional checks verify support and degree
identities, the connected degree-one witness, extraction of the downset
polynomial, the unique-downset criterion for ordinal cuts, the two-coordinate
extraction of each ordinal block, and disjoint-union multiplicativity for
926 ordered summand pairs of total size at most 7.

These are finite exact checks. They establish neither the unbounded
reconstruction theorem nor polynomial irreducibility in all sizes. The
proposed positive settlement uses a general argument, with the finite census
serving as a check on the definitions and proof route.
