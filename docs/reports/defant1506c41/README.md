# Defant, Conjecture 4.1

Run `python3 docs/reports/defant1506c41/check.py` with Python 3.12 or later. The output is in `check.out`.

The program enumerates the divisor representatives in Defant's half-open sectors by an exact coordinate bound and integer divisibility tests. It reproduces the examples from Remark 2.2 and after Definition 2.2. For the proposed counterexample at radicand −11 it checks both divisor multisets, the norm discrepancy and the common index 16/9. It also checks small instances of the norm-transfer formula and the first six members of the family obtained by multiplying both elements by powers of 2. [Defant, arXiv:1506.05416v1](https://arxiv.org/abs/1506.05416v1)
