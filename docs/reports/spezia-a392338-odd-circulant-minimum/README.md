# Odd permutation circulants: OEIS A392338

Source: Stefano Spezia, [A392338](https://oeis.org/A392338/internal), internal
revision 22; [A084367](https://oeis.org/A084367/internal) gives m(2m+1)^2.
The odd-order conjecture asks whether the least nonzero absolute determinant
is n^2(n-1)/2 for every odd n >= 3.

Run with Python 3 and its standard library:

```sh
python3 check.py
```

`output.txt` is the exact output. The final line is `ALL_CHECKS_OK`.

- Fidelity: exhaustively reproduce all seven published minima for n=2,...,8,
  including the displayed order-four example. Fixing the initial zero removes
  only cyclic rotations of the first row; those permute matrix columns and
  preserve absolute determinant. Counts are (n-1)!.
- Proposed family: a_j=j for even j and a_j=n-1-j for odd j. At every odd
  n=3,...,27, verify the permutation, C(I+P)^2=I-P+4mJ, det(I+P)=2,
  det(I-P+tJ)=t*n^2 for t=-2,0,1,4m, and det(C)=m*n^2, with n=2m+1.
  Bareiss integer elimination and separate Fraction Gaussian elimination
  agree on each family determinant. All cofactors of I-P are checked to
  equal 1 for odd n<=11.
- General margin test: 144 integer matrices generated by integral 2x2
  margin-preserving moves have row and column sums nm. Check the reduced
  determinant factorization and divisibility by m*n^2.

All evidence uses integers or exact rational numbers. These are finite checks,
not a proof for unbounded n. The proposed universal argument belongs to the
preregistration; no Lean proof is part of this experiment.
