# Genevois Question 9.4

Run `python3 check.py` with Python 3.12 or newer. The script uses only the standard library and exact integer operations. The expected stdout is in `check.out`.

The two-factor check verifies the twist relations in Example 2.6 and the stable-standard intersection formula in Corollary 3.7 on the 64-element model. It enumerates every standard parabolic and all its conjugates and checks the strict stabilizer inclusion in the proposed geometric argument. The lamp check uses translation of binary configurations and verifies the intersection for every cyclic subgroup at top orders 2 through 8. [arXiv:2505.09194v1](https://arxiv.org/abs/2505.09194v1)
