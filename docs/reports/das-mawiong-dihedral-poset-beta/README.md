# Das–Mawiong beta(D₄) preregistration check

`check.py` uses only exact finite permutation calculations. It verifies the
six-point poset consisting of two disjoint three-point V-posets, checks that
its full automorphism group has order eight and satisfies the standard
dihedral presentation, and checks the orbit obstruction used for the lower
bound on five or fewer points. The final line `ALL_CHECKS_OK` is the required
success marker.
